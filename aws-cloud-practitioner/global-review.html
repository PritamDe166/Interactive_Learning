AWS CLF-C02 / Global infrastructure / Section review

Global infrastructure: review

  • Route users: Route 53 (DNS, routing policies, failover for DR).
  • Speed up delivery: CloudFront (cache), S3 Transfer Acceleration (uploads to one bucket), Global Accelerator (static IPs, TCP/UDP, failover).
  • Move AWS closer: Local Zones (city), Wavelength (5G), Outposts (your data centre).
  • Architectures: single AZ → multi-AZ → active-passive → active-active.

Section summary

Routing

  • Route 53: managed DNS, A/Alias records, health checks.
  • Policies: simple, weighted, latency, failover, geolocation…

Delivery speed

  • CloudFront: CDN cache at edge locations; S3 origin with OAC; Shield/WAF.
  • S3 Transfer Acceleration: edge + AWS network for uploads to one bucket.
  • Global Accelerator: 2 static anycast IPs, any TCP/UDP, fast failover, no cache.

Closer to users

  • Local Zones: Region extension in a city (Delhi, Kolkata…).
  • Wavelength: inside 5G networks.
  • Outposts: AWS racks in your data centre; you secure them physically.

Architectures

  • Multi-AZ = HA, no global latency gain.
  • Active-passive = fast global reads, central writes.
  • Active-active = fast reads and writes everywhere (DynamoDB global tables).

Commonly confused pairs

PairThe difference
CloudFront vs Global AcceleratorCaches HTTP content vs proxies any TCP/UDP with static IPs, no cache
CloudFront vs S3 CRRCache at many edges vs full copy in one other Region
Transfer Acceleration vs CloudFrontFaster transfers to one bucket vs cached reads for many users
Route 53 vs Global AcceleratorDNS answers (cached by clients) vs network-level routing with static IPs
Local Zones vs Wavelength vs OutpostsA city vs a 5G network vs your data centre
Active-passive vs active-activeWrites in one Region vs writes in every Region
Multi-AZ vs multi-RegionSurvives a data-centre failure vs also serves distant users and survives a Region failure

Section cheat-sheet

  • Managed DNS→Route 53
  • DR with DNS→Failover routing
  • Lowest latency Region→Latency routing
  • CDN, cache→CloudFront
  • Faster S3 uploads→Transfer Acceleration
  • Static IPs, TCP/UDP, failover→Global Accelerator
  • AWS in your data centre→Outposts
  • 5G edge→Wavelength
  • City-level latency→Local Zones
  • Global writes→Active-active
