AWS CloudFormation

  • CloudFormation is AWS's infrastructure as code: a template (YAML/JSON) declares your resources.
  • It creates them as a stack, in the right order, and updates or deletes them together.
  • The same template gives identical environments in any Region or account.
  • Drift detection finds resources changed by hand.

In terms you know

AWSClosest thing you knowThe difference
TemplateAn ARM template, or a PowerShell DSC configuration for infrastructureDeclarative; CloudFormation works out the steps.
StackA resource group created from one deploymentUpdated and deleted as a unit.

Walkthrough: from console clicks to a template

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CloudFormation = AWS-native infrastructure as code (IaC).
  2. Templates in YAML or JSON; declarative (desired end state).
  3. A stack = the resources one template created; created in dependency order, deleted together.
  4. Repeatable across Regions and accounts: dev/test/prod, disaster recovery.
  5. Stack resources are tagged, which helps with cost tracking; templates can be cost-estimated.
  6. Drift detection shows resources that no longer match the template.
  7. Free; you pay for the resources created. Beanstalk and the CDK use it underneath.
