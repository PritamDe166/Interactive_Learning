AWS CLF-C02 / Deployment & infrastructure / 9 · Domain 3 Technology

AWS CodePipeline

  • CodePipeline orchestrates CI/CD: it moves each change through source, build, test and deploy stages.
  • It doesn't build or deploy itself; it calls CodeBuild, CodeDeploy, Beanstalk, CloudFormation, GitHub, Jenkins…
  • A failed stage stops the release.

In terms you know

AWSClosest thing you knowThe difference
CodePipelineAn Azure DevOps or GitHub Actions pipeline definitionThe stages call AWS (or third-party) tools.

Walkthrough: the clinic API's path from commit to servers

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CodePipeline = orchestrates CI/CD: source → build → test → deploy.
  2. Integrates CodeCommit, GitHub, CodeBuild, Jenkins, CodeDeploy, Beanstalk, CloudFormation, ECS, Lambda.
  3. Doesn't compile or deploy by itself.
  4. Fast delivery, automatic, stops on failure; optional manual approval.

Cheat-sheet

  • Orchestrate CI/CD→CodePipeline
  • Build stage→CodeBuild
  • Deploy stage to servers→CodeDeploy
  • Source stage→CodeCommit / GitHub
