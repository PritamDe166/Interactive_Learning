AWS Cloud Development Kit (CDK)

  • The CDK defines infrastructure in a programming language: TypeScript, Python, Java, C#/.NET, Go.
  • It synthesises a CloudFormation template; CloudFormation still does the deploying.
  • Good for developer productivity: loops, types, reuse, tests.

In terms you know

AWSClosest thing you knowThe difference
CDKWriting C# that generates an ARM templateSame idea for CloudFormation, with high-level building blocks.

Walkthrough: from C# code to a running stack

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CDK = define cloud infrastructure using a familiar programming language.
  2. Languages: TypeScript, JavaScript, Python, Java, C#/.NET, Go.
  3. cdk synth → CloudFormation template; cdk deploy → CloudFormation stack.
  4. Doesn't replace CloudFormation; it builds on it.
  5. Infrastructure and application code can live together and be unit-tested.
