Amazon S3

  • Object storage: files (objects) in buckets, reached by API or URL. Virtually unlimited; objects up to ~48.8 TiB.
  • A bucket lives in one Region; its name is globally unique. "Folders" are just key prefixes.
  • Private by default, encrypted by default (SSE-S3). Access comes from IAM policies and bucket policies.
  • 11 nines durability in every storage class; classes trade price against retrieval speed and availability.

More S3 you'll be asked about

Replication

CRR (cross-Region): compliance, lower latency, other accounts. SRR (same Region): aggregate logs, prod → test copies. Needs versioning on both buckets; asynchronous; only new objects (existing ones need S3 Batch Replication).

Encryption

SSE-S3: default on every new object since January 2023, free. SSE-KMS: keys in KMS, usage audited in CloudTrail. Client-side: you encrypt before upload. In transit: HTTPS.

Static website

Turn on website hosting, add index.html, make it public (BPA off + policy). The website endpoint is HTTP only: put CloudFront in front for HTTPS and a custom domain.

Storage Gateway

Hybrid bridge from on-premises to S3: S3 File Gateway (NFS/SMB), Volume Gateway (iSCSI, EBS snapshots), Tape Gateway (virtual tapes → S3 Glacier).

Access checks

IAM Access Analyzer for S3 lists buckets that are public or shared with other accounts. Pre-signed URLs give time-limited access to a private object.

Lock it down

MFA Delete: MFA for permanent deletes (root only). Object Lock / Glacier Vault Lock: write-once-read-many (WORM) for compliance.

Corrected

Maximum object size is 48.8 TiB (multipart, 10,000 parts of up to 5 GiB), not 50 TB; older material says 5 TB. A single PUT is limited to 5 GB, and multipart is recommended from about 100 MB.

Corrected

Existing objects are replicated with S3 Batch Replication, not "S3 Batch Operations" in general. Replication has no time guarantee unless you pay for Replication Time Control (15-minute SLA).

Updated

Snowball devices reach end of support on 31 December 2026 in commercial Regions, and the Snow Family isn't on the CLF-C02 in-scope list. Know it only as "ship a physical device to move huge data".

Updated

S3 Express One Zone: single-digit-millisecond latency, up to 10× faster than Standard, request costs up to 80% lower, one AZ, "directory buckets". Bucket names can also live in an account regional namespace that only your account can claim.

Added

Pricing levers: you pay for GB-months stored, requests, retrievals (IA and Glacier) and data transfer out. Data in is free. Every version of an object is billed as a full object, so pair versioning with lifecycle expiration.

Check yourself

Answer out loud before you open each card.

Which two things must be true for anonymous users to read objects?Show answer

Block Public Access off AND a bucket policy granting public s3:GetObject.

Versioning is on and someone deletes a file. How do you get it back?Show answer

The delete only added a delete marker. Remove the marker and the previous version is current again.

Access pattern unknown and changing; no retrieval fees wanted. Which class?Show answer

S3 Intelligent-Tiering (small monitoring fee per object, no retrieval fees).

Cheapest class for records kept 10 years, retrieval within 12 hours is fine?Show answer

S3 Glacier Deep Archive.

What must be enabled on both buckets before setting up replication?Show answer

Versioning.

Your S3 static website needs HTTPS. What do you add?Show answer

Amazon CloudFront in front of the bucket (the website endpoint is HTTP only).
