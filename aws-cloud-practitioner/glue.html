AWS CLF-C02 / Databases & analytics / 15 · Domain 3 Technology

AWS Glue

  • Glue is a serverless ETL service: extract, transform and load data for analytics.
  • Crawlers discover data and record its schema in the Glue Data Catalog.
  • Athena, Redshift Spectrum and EMR use the catalog to query the data.

In terms you know

AWSClosest thing you knowThe difference
Glue ETL jobAn SSIS packageServerless and Spark-based; no Integration Services server to run.
Data CatalogA central list of table definitions, like a metadata repositoryShared by Athena, Redshift and EMR.

Walkthrough: turning raw exports into query-ready data

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Glue = managed, serverless ETL (extract, transform, load).
  2. Crawlers infer schemas; the Data Catalog stores table metadata.
  3. The Data Catalog is used by Athena, Redshift Spectrum and EMR.
  4. Typical job: clean, join and convert data to Parquet for cheaper queries.
  5. Glue prepares data; DMS migrates databases.

Cheat-sheet

  • ETL→Glue
  • Prepare data for analytics→Glue
  • Metadata catalog for Athena→Glue Data Catalog
  • Discover schemas automatically→Glue crawler
  • Migrate a database→DMS, not Glue
  • Streaming data ingestion→Kinesis

Reference

PartJob
CrawlerScans data and infers the schema
Data CatalogStores table definitions
ETL jobTransforms and loads data (serverless Spark or Python)

Kinesis (in scope, mentioned in the pipeline lab) ingests real-time streaming data; Firehose can deliver it to S3 for Glue and Athena.
