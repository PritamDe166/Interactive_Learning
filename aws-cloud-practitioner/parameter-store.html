AWS CLF-C02 / Deployment & infrastructure / 13 · Domain 2 Security

Parameter Store

  • Parameter Store stores configuration and secrets centrally (part of Systems Manager).
  • String for plain values; SecureString encrypted with KMS.
  • Access controlled per parameter with IAM; every change is versioned.
  • Standard tier free; Advanced tier paid.

In terms you know

AWSClosest thing you knowThe difference
Parameter StoreAzure App Configuration / Key Vault, or a central settings databaseRead through IAM-authorised API calls; secrets encrypted with KMS.

Walkthrough: moving the database password out of appsettings.json

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Parameter Store = secure storage for configuration and secrets.
  2. Types: String (plain), StringList, SecureString (encrypted with KMS).
  3. Hierarchical names, e.g. /clinic/prod/db-password.
  4. Access via IAM (and KMS permissions for SecureString).
  5. Each change creates a new version.
  6. Standard tier free; Advanced tier paid (larger values, parameter policies).
  7. Related: AWS Secrets Manager (automatic rotation).

Cheat-sheet

  • Store configuration and secrets→Parameter Store
  • Encrypted parameter→SecureString (KMS)
  • Control who reads a parameter→IAM
  • Automatic password rotation→Secrets Manager
