AWS CLF-C02 / Deployment & infrastructure / 12 · Domain 2 Security

Session Manager

  • Session Manager opens a shell on EC2 or on-premises servers with no SSH keys, no bastion and port 22 closed.
  • Needs the SSM agent and an IAM role (AmazonSSMManagedInstanceCore).
  • IAM controls access; sessions can be logged to S3 or CloudWatch.

In terms you know

AWSClosest thing you knowThe difference
Session ManagerRemote PowerShell through a central gateway, with no RDP/SSH ports openAccess controlled by IAM and fully logged.

Walkthrough: a shell without opening port 22

Points to remember

  1. Session Manager = secure shell to EC2 and on-premises servers.
  2. No SSH access, no bastion hosts, no SSH keys; port 22 can stay closed.
  3. Needs the SSM agent and an IAM role with AmazonSSMManagedInstanceCore.
  4. Linux, macOS and Windows.
  5. Session logs to S3 or CloudWatch Logs.

Cheat-sheet

  • Shell without SSH / port 22→Session Manager
  • Requirement on the instance→SSM agent + IAM role
  • Log every session→S3 or CloudWatch Logs
  • Browser SSH with temporary keys (port 22 open)→EC2 Instance Connect
