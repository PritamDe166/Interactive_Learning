AWS CLF-C02 / Databases & analytics / 7 · Domain 3 Technology

Amazon Redshift

  • Redshift is a data warehouse for analytics (OLAP), not for day-to-day transactions (OLTP).
  • It stores data in columns and spreads queries over many nodes (MPP), scaling to petabytes.
  • Data is loaded in batches from databases and S3; you query it with SQL and BI tools.
  • Run a provisioned cluster or Redshift Serverless.

Points to remember

  1. Redshift = data warehouse for OLAP (analytics), based on PostgreSQL-style SQL.
  2. Columnar storage + MPP (massively parallel processing); petabyte scale.
  3. Load data in batches (from S3, RDS, Glue ETL…), not row-by-row transactions.
  4. Integrates with BI tools: QuickSight, Tableau.
  5. Redshift Serverless: no clusters to manage, pay for use. Provisioned clusters can use Reserved Instances.
  6. OLTP (RDS/Aurora) = many small transactions, row-based. OLAP (Redshift) = big analytical queries, columnar.

Cheat-sheet

  • Data warehouse→Redshift
  • OLAP, analytics on structured data→Redshift
  • Columnar, MPP, petabytes→Redshift
  • Day-to-day transactions→RDS / Aurora (OLTP)
  • SQL on S3 files, no loading, serverless→Athena
  • Warehouse without managing a cluster→Redshift Serverless
