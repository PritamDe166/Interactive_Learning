Amazon API Gateway

  • API Gateway creates, publishes, secures and monitors APIs, fully managed and serverless.
  • It gives Lambda functions an HTTPS endpoint: API Gateway + Lambda = a serverless API.
  • Adds authentication, API keys, throttling and monitoring.
  • Supports REST/HTTP and WebSocket APIs.

In terms you know

AWSClosest thing you knowThe difference
API GatewayAzure API Management, or an IIS reverse proxy with auth and rate limiting in front of your Web APIServerless; you never run the proxy.

Points to remember

  1. API Gateway = fully managed, serverless service to create, publish, maintain, monitor and secure APIs.
  2. Lambda isn't an HTTP API by default; API Gateway proxies requests to it.
  3. Features: authentication (IAM, Cognito, authorizers), API keys, throttling, caching, stages, CloudWatch monitoring.
  4. API types: REST, HTTP and WebSocket (real-time).
  5. Classic serverless stack: API Gateway + Lambda + DynamoDB.

Cheat-sheet

  • Serverless REST API→API Gateway + Lambda
  • Expose Lambda over HTTPS→API Gateway
  • Limit requests per client→Throttling / usage plans
  • Real-time two-way API→WebSocket API
  • Partners need keys→API keys
