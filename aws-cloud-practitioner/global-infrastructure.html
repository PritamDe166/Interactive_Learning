Global Infrastructure

  • Going global gives lower latency, disaster recovery and resilience against attacks.
  • Route 53 (DNS) decides which Region a user is sent to.
  • CloudFront caches content at edge locations. Global Accelerator carries traffic over AWS's network, no caching, two static IPs.
  • S3 Transfer Acceleration speeds up long-distance uploads to one bucket via the nearest edge.
  • Regions, AZs and edge locations themselves are on Cloud Computing Basics; DNS basics on Client-Server & DNS.

Exam cheat-sheet

  • Lowest latency Region per user→Route 53 latency routing
  • Primary / backup Region→Route 53 failover routing
  • CDN, cache static content→CloudFront
  • Static IPs, TCP/UDP, fast regional failover→Global Accelerator
  • Faster uploads to a distant S3 bucket→S3 Transfer Acceleration
  • Run AWS on-premises→Outposts

LatencyTo the Region with the lowest latency for themGlobal performance

Geoproximity · IP-based · MultivalueBy distance with bias · by client IP range · several healthy answersRarely asked at this level

Records

A → IPv4, AAAA → IPv6, CNAME → another name (not at the zone apex), Alias → an AWS resource (ELB, CloudFront, S3 website), free and allowed at the apex.

CloudFront origins

S3 bucket kept private with Origin Access Control (CloudFront adds the bucket policy), a load balancer or EC2 (also private via VPC origins), or any HTTP server. Works with Shield and WAF.

CloudFront vs S3 replication

CloudFront: cache read-heavy static content at hundreds of edges, served until the TTL expires (default 24 h). S3 CRR: a full, near-real-time copy of a bucket in a few chosen Regions.

Updated

CloudFront now has 750+ points of presence (plus regional edge caches), not the ~216 quoted in the course. AWS runs 39 Regions with 124 AZs (October 2026); counts change, so the exam won't test them.

Added

Route 53 has more than four routing policies. The course covers Simple, Weighted, Latency and Failover; Geolocation is the next most common on exams. Health checks are optional for Weighted and Latency and required for Failover's primary.

Added

Edge location ≠ Region. You can't run your app on an edge location; CloudFront, Route 53, Global Accelerator and Transfer Acceleration use them. To run compute closer to users, AWS has Local Zones, Wavelength (5G networks) and Outposts (in your data centre).

Added

Costs: a hosted zone is about $0.50/month plus queries; domains bill yearly and auto-renew. CloudFront has a free tier and flat-rate plans; Global Accelerator charges hourly plus premium data transfer; Transfer Acceleration charges per GB only when it actually speeds things up.
