AWS CLF-C02 · IAM · Domain 2 Security & Compliance

IAM security tools

  • Two built-in audit tools, two questions. Credential report: whose credentials are weak? Access Advisor: which permissions are never used?
  • The credential report is account-level: a CSV of every user (and root) with password, MFA and access-key status.
  • Access Advisor (the "Last accessed" tab) shows, for a user, group, role or policy, which services it can use and when it last used them.
  • Both serve least privilege: fix weak credentials, remove permissions nobody uses.

Points to remember

  1. IAM credential report = account-level, downloaded as CSV. Lists all IAM users and the root user with: password enabled / last used / last changed, MFA active, access keys active / last rotated / last used, certificates.
  2. Use it to find: users without MFA, old or unused access keys, old passwords, stale users.
  3. It can be generated once every 4 hours; AWS keeps one report.
  4. IAM Access Advisor = last accessed information for a user, group, role or policy: which services it is allowed to use, which policy grants them, and when each was last accessed (tracked for at least 400 days).
  5. Use it to remove unused permissions: if a user with AdministratorAccess only ever touches EC2 and S3, narrow their policy.
  6. Exam trigger words: "which users have no MFA / old keys" → credential report; "which services has this user used" → Access Advisor.
  7. Related (later topics): IAM Access Analyzer finds resources shared publicly or with other accounts; AWS Trusted Advisor flags root without MFA; CloudTrail is the full log of API calls.

Which tool?

In the console

Run both tools (from the course hands-on)
  1. IAM → Credential report → Download credential report. Open the CSV.
  2. Check the <root_account> row first: MFA should be true and there should be no access keys.
  3. For each user check mfa_active, password_last_used, access_key_1_last_rotated, access_key_1_last_used_date.
  4. IAM → Users → (a user) → Last accessed tab. See every service the user may use, the policy that grants it, and when it was last used.
  5. For services never used, narrow the user's policies.

Exam cheat-sheet

  • List of all users and the status of their credentials→Credential report (account-level, CSV)
  • Services a user can access and when last used→IAM Access Advisor
  • Remove permissions nobody uses→Access Advisor → least privilege
  • Find users without MFA→Credential report
