AWS CLF-C02 / Global infrastructure / 9 · Domain 1 Concepts

Global Application Architectures

  • Single Region, single AZ: simple, no HA. Single Region, multi-AZ: HA, no global latency benefit.
  • Multi-Region active-passive: fast reads worldwide, writes in one Region.
  • Multi-Region active-active: fast reads and writes everywhere; hardest (e.g. DynamoDB global tables).

Walkthrough: from one AZ to active-active

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Four designs, simplest to hardest: single Region/single AZ → single Region/multi-AZ → multi-Region active-passive → multi-Region active-active.
  2. Multi-AZ = high availability, but no latency gain for distant users.
  3. Active-passive: passive Regions serve reads; all writes go to the active Region.
  4. Active-active: every Region reads and writes; best global latency; most complex.
  5. DynamoDB global tables are an active-active database.

Cheat-sheet

  • High availability in one Region→Multi-AZ
  • Fast global reads, central writes→Active-passive
  • Fast global reads and writes→Active-active
  • Active-active NoSQL example→DynamoDB global tables
