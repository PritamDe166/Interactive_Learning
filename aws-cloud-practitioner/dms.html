AWS CLF-C02 / Databases & analytics / 16 · Domain 3 Technology

AWS Database Migration Service (DMS)

  • DMS migrates databases to AWS (or between databases) while the source stays operational.
  • It copies existing data, then replicates ongoing changes, so downtime is minimal.
  • Homogeneous (Oracle → Oracle) or heterogeneous (Oracle → Aurora PostgreSQL); heterogeneous needs schema conversion (SCT).

In terms you know

AWSClosest thing you knowThe difference
DMSTransactional replication used to move a database, then switching the connection stringManaged, and works across different engines.
SCTSQL Server Migration Assistant (SSMA)Converts schemas and code between engines.

Walkthrough: Oracle on-premises to Aurora PostgreSQL

Points to remember

  1. DMS = migrate databases quickly and securely; the source remains operational.
  2. Full load + ongoing replication (change data capture) → minimal downtime.
  3. Homogeneous: same engine. Heterogeneous: different engines, schema converted with SCT (or DMS Schema Conversion).
  4. DMS moves the data; SCT converts the schema.
  5. Sources/targets: on-premises, EC2, RDS, Aurora, S3, Redshift and more.

    Cheat-sheet

    • Migrate a database with minimal downtime→DMS
    • Convert schema between different engines→SCT
    • Same engine migration→Homogeneous: DMS only
    • Different engines→Heterogeneous: SCT + DMS
