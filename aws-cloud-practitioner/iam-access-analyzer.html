AWS CLF-C02 / Amazon S3 / 8 · Domain 2 Security

IAM Access Analyzer for S3

  • IAM Access Analyzer for S3 shows which buckets are public or shared with other AWS accounts.
  • It analyses bucket policies, ACLs and access point policies; you first create an analyzer in IAM for the Region.
  • You review each finding: archive it if intended, fix it if not (one-click Block Public Access).
  • It reports; it never changes permissions itself.

In terms you know

AWSClosest thing you knowThe difference
Access AnalyzerA permissions audit report that lists every share open to "Everyone" or to another domainRuns continuously and reasons over the policies instead of sampling them.

Walkthrough: finding the buckets that leak

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Purpose: find buckets accessible publicly or from other AWS accounts.
  2. It analyses bucket policies, ACLs, access point policies and Multi-Region Access Point policies.
  3. Needs an account-level (or organization-level) analyzer created in IAM, per Region.
  4. Findings show the bucket, the kind of access and its source (policy or ACL).
  5. Review: archive intended findings; block public access or edit the policy for unintended ones.
  6. It does not fix anything automatically.

In the console

Review S3 findings (outline)
  1. IAM → Access Analyzer → Create analyzer: type external access, zone of trust = current account.
  2. S3 → IAM Access Analyzer for S3 (left menu): buckets with public or cross-account access are listed.
  3. Select a finding you intended (e.g. a website bucket) → Archive. For an unintended one, use Block all public access or open the bucket and edit its policy.

Cheat-sheet

  • Which buckets are public or shared with other accounts?→IAM Access Analyzer for S3
  • Does it fix permissions?→No, you review and act
  • Expected public website bucket→Archive the finding
  • Sensitive data (PII) inside buckets→Amazon Macie
  • Prevent public buckets in the first place→Block Public Access

Reference

ToolAnswers the question
IAM Access Analyzer for S3Who outside my account can reach this bucket?
Block Public AccessStop any public grant from working
Amazon MacieWhich buckets contain sensitive data?
Trusted AdvisorAccount-wide best-practice checks, including open buckets (on eligible support plans)

Exam scope. Access Analyzer appears lightly on CLF-C02; know what it answers and how it differs from Macie and Block Public Access.
