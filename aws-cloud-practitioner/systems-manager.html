AWS Systems Manager (SSM)

  • Systems Manager manages EC2 and on-premises servers at scale: a hybrid service.
  • Each server runs the SSM agent and needs permission (an IAM role on EC2).
  • Run commands, patch the fleet, open shells, store parameters, collect inventory.

In terms you know

AWSClosest thing you knowThe difference
Systems ManagerSCCM / WSUS plus remote PowerShell for every serverWorks across Windows, Linux, AWS and on-premises from one console.

Walkthrough: patching a hybrid fleet

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Systems Manager = manage a fleet of EC2 and on-premises systems at scale (hybrid).
  2. Needs the SSM agent on each server (default on Amazon Linux, some Ubuntu and Windows AMIs) plus an IAM role / permissions.
  3. Features: Run Command, Patch Manager, Session Manager, Parameter Store, Inventory, Automation, State Manager.
  4. Works on Windows and Linux.
  5. Exam triggers: "patch a fleet", "run a command across many servers", "hybrid".
