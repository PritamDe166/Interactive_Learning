IAM roles for EC2

  • Software on an instance that calls AWS (CLI, SDK) needs credentials. The right way: attach an IAM role to the instance.
  • The role reaches the instance through an instance profile; the CLI and SDK fetch its temporary credentials automatically, so no aws configure.
  • Never type your personal access keys into an instance: anyone who gets onto the box can copy them.
  • The role can do only what its permissions policy allows. Remove the policy and the same command gets AccessDenied.

Points to remember

  1. Workloads on EC2 get AWS permissions from an IAM role attached to the instance, never from stored access keys.
  2. The role is wrapped in an instance profile; the console creates it for you when you attach the role.
  3. On the instance, the CLI/SDK read temporary credentials from the instance metadata service and refresh them automatically.
  4. The role needs a trust policy for ec2.amazonaws.com and permissions policies (course: IAMReadOnlyAccess on DemoRoleForEC2).
  5. Attach: Instance → Actions → Security → Modify IAM role. One role per instance at a time; you can change it while it runs.
  6. Remove the policy → AccessDenied; add it back → may take a few seconds to propagate.
  7. Anyone who can run commands on the instance can use its role: keep the OS patched and the role least-privilege.
  8. Never put keys in user data, scripts, code or config files on the instance.

In the console

Attach the role (from the course hands-on)
  1. Connect to the instance (EC2 Instance Connect). aws --version: the CLI is preinstalled on Amazon Linux.
  2. aws iam list-users → Unable to locate credentials. Don't fix it with aws configure.
  3. EC2 → select instance → Actions → Security → Modify IAM role → choose DemoRoleForEC2 → Save. Check the instance's IAM role field.
  4. Run aws iam list-users again: the users are listed. No keys were configured.
  5. In IAM, detach IAMReadOnlyAccess from the role → the command returns AccessDenied. Re-attach; wait a moment; it works again.

The CLI on an instance says "Unable to locate credentials". Correct fix?Show answer

Attach an IAM role to the instance (not aws configure with your keys).

A role is attached but the command returns AccessDenied. Why?Show answer

The role's permissions policy doesn't allow that action (or a change hasn't propagated yet).

What is an instance profile?Show answer

The container that attaches an IAM role to an EC2 instance; the console creates it automatically.
