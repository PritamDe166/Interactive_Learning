AWS CLF-C02 / Amazon S3 / 1 · Domain 3 Technology

S3 Buckets & Objects

  • Amazon S3 is object storage: you store whole files (objects) in buckets and reach them over HTTPS.
  • Storage is virtually unlimited; one object can be up to about 48.8 TiB. You pay for what you store and use.
  • A bucket lives in one Region, but its name is unique across all AWS accounts.
  • An object's key is its full name; "folders" are only prefixes in the key.

Points to remember

  1. S3 is object storage: virtually unlimited, pay per GB-month, per request and for data transferred out. Data transferred in is free.
  2. A bucket is created in one Region. Its name must be globally unique: 3 to 63 characters, lowercase letters, numbers, dots and hyphens, starting and ending with a letter or number.
  3. An object = key + value (the data) + metadata + tags (+ version ID when versioning is on).
  4. The key is the full path, e.g. scans/2026/xray-0042.png = prefix scans/2026/ + object name. There are no real folders.
  5. Maximum object size is about 48.8 TiB. Use multipart upload for big files (required above 5 GB, recommended from about 100 MB).
  6. S3 Standard stores data across at least 3 AZs; durability is 11 nines for every storage class.
  7. Buckets are private by default; a pre-signed URL gives temporary access to one object.

    In the console

    Create a bucket and upload a file (outline)
    1. S3 → Create bucket: pick the Region and a unique name. Leave Block all public access on and default encryption (SSE-S3) as it is.
    2. Upload a file, then open it: the Open button works (it uses a pre-signed URL), but the plain Object URL returns AccessDenied because the bucket is private.
    3. Create folder and upload into it, then look at the object's key: the "folder" is just a prefix.
    4. Clean up: empty the bucket, then delete it.

    Cheat-sheet

    • Object storage, virtually unlimited→Amazon S3
    • Backups, archives, media, data lake→S3
    • Must a bucket name be unique?→Yes, across all accounts
    • Where does a bucket live?→One Region
    • Folder in S3→Key prefix
    • Upload a 20 GB file→Multipart upload
    • Temporary link to a private object→Pre-signed URL
    • How durable?→11 nines

    What you pay for. Storage (per GB-month, by storage class), requests (PUT, GET…), retrievals from IA and Glacier classes, and data transferred out to the internet or another Region. Uploads (data in) and transfers to other AWS services in the same Region are free.

    Account regional namespace. As an alternative to the shared global namespace, a bucket can be created with a name of the form prefix-<accountId>-<region>-an, which only your account can use.

    Express One Zone uses a different kind of bucket (a directory bucket) in a single AZ for very low latency; see storage classes.

    Check yourself

    Answer out loud before you open each card.

    Is an S3 bucket global or Regional?Show answer

    The bucket and its data are in one Region. Only the name is unique globally.

    What is the "folder" in reports/2026/june.pdf?Show answer

    The prefix reports/2026/, part of the key. S3 has no real folders.

    Can one object be 100 TB?Show answer

    No. The maximum object size is about 48.8 TiB. You can store unlimited objects, though.

    A doctor without an AWS account must download one private scan. What do you give them?Show answer

    A pre-signed URL that expires after a set time.

    S3, EBS or EFS for a data lake?Show answer

    S3.

    Does durability differ between storage classes?Show answer

    No, all are designed for 11 nines. Availability differs.
