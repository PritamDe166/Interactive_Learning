AWS Lambda

  • Lambda runs your code as functions when an event happens: no servers, scales automatically.
  • Limits: 15 minutes per run, 128 MB–10 GB memory.
  • Permissions come from an IAM execution role; logs go to CloudWatch.
  • You pay per request and per GB-second of run time; idle costs nothing.

In terms you know

AWSClosest thing you knowThe difference
Lambda functionAn Azure Function or a Windows service that only wakes up for an eventNo host to manage; each event can run in parallel.
Execution roleThe app pool identity of an IIS siteAn IAM role that grants exactly what the function needs.

Points to remember

  1. Lambda = event-driven functions; serverless; pay only when code runs.
  2. Max run time 15 minutes; memory 128 MB to 10,240 MB; /tmp 512 MB to 10 GB.
  3. Runtimes: Node.js, Python, Java, C#/.NET, Ruby, custom runtime API.
  4. Pricing: requests ($0.20 per 1M) + duration in GB-seconds; free tier 1M requests + 400,000 GB-s per month.
  5. Triggers: S3, API Gateway, EventBridge (schedules), DynamoDB, SQS, SNS and more.
  6. Permissions via an IAM execution role; monitoring via CloudWatch Logs.
  7. Long jobs or general Docker workloads: use Batch, ECS or Fargate.

Each event runs in an execution environment. A brand-new one takes a little longer to start (a cold start); a warm one is reused and starts faster.

In the console

Create a function (outline)
  1. Lambda → Create function → Author from scratch, runtime .NET 8 or Python, default execution role (it can write to CloudWatch Logs).
  2. Test with a sample event; look at the duration, billed duration and memory used.
  3. Open Monitor → View CloudWatch logs to see the output.
  4. Add a trigger, for example S3 (object created) or an EventBridge schedule; add S3 permissions to the execution role.
  5. Delete the function and its log group when done.

Cheat-sheet

  • Run code without servers, event-driven→Lambda
  • Max Lambda run time→15 minutes
  • Lambda pricing→Requests + duration (GB-seconds)
  • Give Lambda access to S3→IAM execution role
  • Lambda logs→CloudWatch Logs
  • Job longer than 15 minutes→Batch / ECS / Fargate
  • Expose Lambda as an HTTP API→API Gateway
