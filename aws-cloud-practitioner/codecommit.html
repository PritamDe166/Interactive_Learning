AWS CodeCommit

  • CodeCommit is a managed, private Git repository service on AWS.
  • Code stays in your AWS account, secured with IAM and encrypted.
  • It feeds CodeBuild and CodePipeline. After pausing new sign-ups in 2024, it returned to full availability in November 2025.

In terms you know

AWSClosest thing you knowThe difference
CodeCommitAn Azure Repos or on-premises Git serverFully managed inside your AWS account.

Walkthrough: the clinic API's path from commit to servers

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CodeCommit = managed private Git repositories on AWS (version control).
  2. Secured with IAM, encrypted at rest and in transit.
  3. Integrates with CodeBuild, CodePipeline, Jenkins and other CI tools.
  4. Returned to full availability (new customers) on 24 Nov 2025.
