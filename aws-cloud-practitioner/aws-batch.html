AWS CLF-C02 / Other compute / 7 · Domain 3 Technology

AWS Batch

  • Batch runs batch jobs (a start and an end) at any scale.
  • Jobs are Docker images submitted to a job queue.
  • Batch launches EC2 / Spot or Fargate capacity to match the queue, then shrinks it.
  • No time limit (unlike Lambda); Batch itself is free.

In terms you know

AWSClosest thing you knowThe difference
AWS BatchA job scheduler (SQL Agent jobs or an HPC queue) that also buys and returns the serversCapacity appears for the queue and disappears afterwards.

Points to remember

  1. Batch = fully managed batch processing at any scale.
  2. Jobs are Docker images in a job queue.
  3. Provisions EC2 / Spot (or Fargate) automatically; runs on ECS/EKS underneath.
  4. No 15-minute limit; good for long jobs.
  5. No charge for Batch; pay for the compute. Spot cuts cost.
  6. Managed, not serverless on EC2.

Cheat-sheet

  • Batch jobs, start and end, any scale→AWS Batch
  • Jobs over 15 minutes in Docker→AWS Batch
  • Cheapest capacity for batch→Spot Instances
  • Batch charge→Only the underlying compute
