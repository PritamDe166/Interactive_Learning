CloudFormation vs CDK vs Beanstalk

  • CloudFormation: most control, templates, repeatable everywhere.
  • CDK: the same, written in a programming language.
  • Beanstalk: least effort for a standard web app (PaaS).

Walkthrough: from most control to least effort

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. "Template", "infrastructure as code", "repeatable", "stack" → CloudFormation.
  2. "Programming language", "developer", "synthesise" → CDK.
  3. "PaaS", "upload code", "least operational overhead for a web app" → Beanstalk.
  4. All three end up using CloudFormation.

Cheat-sheet

  • Total control, existing templates→CloudFormation
  • Developer productivity, programming logic→CDK
  • Quickly deploy a standard web app→Elastic Beanstalk
