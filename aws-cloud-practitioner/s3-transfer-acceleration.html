AWS CLF-C02 / Global infrastructure / 4 · Domain 3 Technology

S3 Transfer Acceleration

  • S3 Transfer Acceleration speeds up transfers to and from one S3 bucket over long distances.
  • Clients upload to the nearest edge location; AWS carries the data over its private network.
  • No caching; extra per-GB fee, charged only when it actually helped.

Walkthrough: a lab in São Paulo uploading to Mumbai

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Speeds up long-distance uploads and downloads for an S3 bucket.
  2. Uses edge locations + the AWS backbone; special accelerate endpoint.
  3. Enabled per bucket.
  4. Doesn't cache (unlike CloudFront).
  5. Extra fee per GB, only when faster.
