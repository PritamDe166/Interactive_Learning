AWS CLF-C02 / Databases & analytics / 11 · Domain 3 Technology

Amazon DocumentDB

  • DocumentDB is a managed document database compatible with MongoDB.
  • It stores JSON documents; storage is replicated across 3 AZs and grows automatically.
  • Think "Aurora, but for MongoDB".

In terms you know

AWSClosest thing you knowThe difference
DocumentDBMongoDB on your own serversManaged: patching, backups, replication and storage growth are handled for you.

Walkthrough: moving a MongoDB app

Points to remember

  1. DocumentDB = managed, MongoDB-compatible document database.
  2. Stores and queries JSON documents.
  3. Storage spread across 3 AZs, grows automatically; read replicas for scale.
  4. Exam trigger: the word "MongoDB".
