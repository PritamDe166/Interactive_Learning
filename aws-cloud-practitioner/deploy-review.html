AWS CLF-C02 / Deployment & infrastructure / Section review

Deployment & infrastructure: review

  • IaC: CloudFormation templates; the CDK generates them from code. PaaS: Elastic Beanstalk.
  • CI/CD: CodeCommit (Git), CodeBuild (build), CodeDeploy (deploy, hybrid), CodePipeline (orchestrate), CodeArtifact (packages).
  • Operations: Systems Manager (hybrid, SSM agent), Session Manager (no SSH), Parameter Store (config and secrets).

Section summary

Infrastructure as code

  • CloudFormation: YAML/JSON templates, stacks, repeatable across Regions and accounts, drift detection.
  • CDK: TypeScript, Python, C#… → CloudFormation.
  • Terraform: third-party, multi-cloud.

Platform

  • Elastic Beanstalk: PaaS, upload code; EC2 + ELB + ASG built for you; free, pay for resources.
  • Pick CloudFormation for control, CDK for developer productivity, Beanstalk for least effort.

Developer tools

  • CodeCommit: private Git (back to GA Nov 2025).
  • CodeBuild: serverless build, pay per minute.
  • CodeDeploy: EC2 + on-premises, agent.
  • CodePipeline: orchestrates. CodeArtifact: NuGet/npm/pip/Maven packages.

Operations

  • Systems Manager: hybrid fleet; Run Command, Patch Manager, Inventory…
  • Session Manager: no port 22, no keys, IAM + logs.
  • Parameter Store: String / SecureString (KMS), IAM, versions.
