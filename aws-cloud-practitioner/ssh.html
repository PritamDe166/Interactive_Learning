SSH into EC2

  • SSH (Secure Shell) opens a remote terminal on a Linux instance over port 22.
  • It uses a key pair: AWS puts the public key on the instance; you keep the private key (.pem, or .ppk for PuTTY). AWS can't give it to you again.
  • Command: ssh -i key.pem ec2-user@<public-ip>. On macOS/Linux, first run chmod 400 key.pem.
  • Windows instances use RDP on 3389 instead. No terminal at all? Use EC2 Instance Connect in the browser (next topic).

Points to remember

  1. SSH = port 22, for Linux. RDP = port 3389, for Windows.
  2. Clients: the ssh command (macOS, Linux, Windows 10+), PuTTY (Windows, uses .ppk), or EC2 Instance Connect (browser).
  3. Key pair: public key on the instance (~/.ssh/authorized_keys), private key on your machine. Download it at creation; it can't be retrieved later.
  4. chmod 400 key.pem: SSH refuses keys that other users can read ("unprotected private key file").
  5. Amazon Linux user name: ec2-user (Ubuntu uses ubuntu).
  6. Use the current public IP; it changes after stop/start.
  7. Timeout → security group doesn't allow 22 from your IP (or wrong IP, instance stopped). Permission denied (publickey) → wrong key or user.
  8. Exit with exit. Commands you run now execute on the instance, not your laptop.

In the terminal

SSH from macOS (from the course hands-on)
  1. Put EC2Tutorial.pem in a folder without spaces in its name; cd there and ls to confirm.
  2. chmod 0400 EC2Tutorial.pem (once).
  3. ssh -i EC2Tutorial.pem ec2-user@<public-ipv4>; type yes to trust the host key the first time.
  4. whoami → ec2-user. You are on the instance. ping to test outbound; Ctrl+C to stop.
  5. exit to leave. After a stop/start, look up the new public IP before reconnecting.
  6. Windows: Windows 10+ has the same ssh command; otherwise PuTTY with a .ppk key (PuTTYgen converts).

Cheat-sheet

  • Connect to Linux EC2 from a terminal→SSH, port 22, key pair
  • Connect to Windows EC2→RDP, port 3389
  • PuTTY key format→.ppk
  • SSH hangs then times out→Security group rule for 22

Check yourself

You lost the .pem file. Can AWS send it again?Show answer

No. AWS only keeps the public key. Use another access method (Instance Connect, Session Manager) or create a new key pair.

What does chmod 400 fix?Show answer

SSH's "unprotected private key file" error: only you may read the key.

ec2-user
