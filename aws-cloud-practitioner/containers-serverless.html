Containers & Serverless

  • Containers package an app with its dependencies. ECR stores the images; ECS (AWS's own) or EKS (Kubernetes) runs them.
  • Fargate runs those containers with no servers to manage.
  • Lambda runs short functions on events, scales automatically, and costs nothing when idle.
  • API Gateway turns Lambda into an HTTP API. Batch runs long jobs; Lightsail is the simple fixed-price option.

API Gateway

Managed, serverless front door for APIs: REST and WebSocket, authentication, throttling, API keys, monitoring. "Serverless API" = API Gateway + Lambda (+ DynamoDB).

Lambda essentials

Languages: Node.js, Python, Java, .NET, Ruby, plus custom runtimes. Permissions come from its execution role; logs go to CloudWatch. EventBridge schedule + Lambda = serverless cron.

Lightsail

Bundled server, storage, database and networking at a fixed monthly price for people new to cloud: WordPress, simple web apps, dev/test. No auto scaling. Usually the distractor.

Corrected

$1 buys about 60,000 GB-seconds of Lambda, not 600,000 ($0.0000166667 per GB-s on x86). Requests cost $0.20 per million. Free tier each month: 1M requests + 400,000 GB-seconds.

Corrected

Lightsail starts at $5/month with a public IPv4 address. The $3.50 bundle is IPv6-only. Managed databases start at $15/month.

Added

"Serverless" ≠ "managed". Batch and ECS on EC2 are managed but run on instances you pay for while they're up. Serverless (Lambda, Fargate, API Gateway, S3, DynamoDB) means no servers to see, automatic scaling, pay for use.

Added

Newer options beyond exam scope: ECS Managed Instances (AWS manages the EC2 for you), ECS Anywhere (on-premises), Lambda function URLs and Lambda Managed Instances. For the exam: Lambda max 15 minutes, Kubernetes → EKS, "no servers for containers" → Fargate. Elastic Beanstalk is in Deployment & IaC.

Check yourself

Answer out loud before you open each card.

Run Docker containers without managing EC2 instances?Show answer

AWS Fargate (with ECS or EKS).

The team already uses Kubernetes on-premises. Which AWS service?Show answer

Amazon EKS. ECS is AWS's own orchestrator, not Kubernetes.

Which two things make up Lambda's price?Show answer

Number of requests and duration × memory (GB-seconds).

A 3-hour nightly job in a Docker image. Lambda or Batch?Show answer

AWS Batch: Lambda stops at 15 minutes. Use Spot to make it cheap.

Where do you store private container images?Show answer

Amazon ECR.

How does a Lambda function get permission to write to DynamoDB?Show answer

Add the permission to its IAM execution role; never embed access keys.
