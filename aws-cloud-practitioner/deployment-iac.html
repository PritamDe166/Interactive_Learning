Deployment & Infrastructure as Code

  • Infrastructure as Code: describe resources in a file, and let AWS create, change and delete them in order. CloudFormation (templates) or CDK (real code that becomes templates).
  • Elastic Beanstalk: PaaS. Upload code; it builds the EC2, load balancer and Auto Scaling for you.
  • CodePipeline orchestrates CodeCommit → CodeBuild → CodeDeploy. CodeArtifact stores packages.
  • Systems Manager runs fleets (patching, commands, Session Manager shells, Parameter Store), on AWS and on-premises.

Updated
CodeCommit is open to new customers again. AWS stopped onboarding new customers in July 2024, then returned CodeCommit to general availability in November 2025. Your notes and older courses may say it's closed.

      
Corrected
CodeBuild doesn't watch your repository on its own. It runs when something triggers it: a webhook, a CodePipeline stage, or a manual start. And CloudFormation uploads a template to S3 only in some cases (for example large templates), not always.

      
Added
Secrets Manager vs Parameter Store: both hold secrets; Secrets Manager adds automatic rotation (for example RDS passwords) and costs per secret. Parameter Store is cheaper and good for configuration. Exam: "rotate database credentials automatically" → Secrets Manager.

      
Added
Drift isn't auto-repaired. Drift detection only reports differences. You fix it by updating the template or reverting the change. Beanstalk itself uses CloudFormation behind the scenes.

Developers want to define infrastructure in Python, deployed by AWS. Which tool?Show answer
        
AWS CDK; it synthesizes CloudFormation templates that CloudFormation deploys.

      
Fastest way to run a standard web app without managing infrastructure?Show answer
        
Elastic Beanstalk (PaaS).

      
Which service orchestrates source → build → deploy?Show answer
        
CodePipeline. CodeBuild builds, CodeDeploy deploys.

      
Shell access to EC2 with port 22 closed and no keys?Show answer
        
Systems Manager Session Manager (SSM agent + IAM role; sessions can be logged).

      
Deploy app updates to EC2 and on-premises servers?Show answer
        
CodeDeploy (hybrid; agent installed on each server).

      
Someone changed a stack resource by hand. What finds it?Show answer
        
CloudFormation drift detection.
