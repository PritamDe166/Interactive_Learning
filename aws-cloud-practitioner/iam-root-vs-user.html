Root account vs IAM user

  • An AWS account is the container: a 12-digit ID, its own resources and one bill.
  • Every account has exactly one root user, created with it, with full and unrestricted access.
  • IAM users are identities inside one account, with only the permissions you grant. An account can have many; a user never spans accounts.
  • A handful of tasks only the root user can do. Everything else should be done by IAM identities.

Points to remember

  1. An AWS account = billing and resource container with a 12-digit account ID.
  2. Exactly one root user per account, created automatically (it signs in with the account email). It has full access that policies can't restrict.
  3. Use root only for root-only tasks. Protect it with MFA (AWS now enforces MFA for root sign-in) and don't create root access keys.
  4. Root-only tasks to know: change the account email, root password or root access keys; close the account; restore permissions when the only IAM admin locked themselves out; activate IAM access to the Billing console; register as a seller in the Reserved Instance Marketplace; configure S3 MFA Delete; edit a bucket policy that denies everyone; sign up for GovCloud.
  5. Not root-only: launching EC2, creating IAM users, changing contact info or the account name. These are distractors in exam questions.
  6. IAM users: many per account, each with only the permissions granted. A user belongs to one account only.
  7. Separate identities contain damage: revoke one leaked user and the account, root and other users are untouched.
  8. Root sign-in shows only the account ID in the console menu; an IAM user shows user @ account.
  9. Companies use several accounts (dev, test, prod) for full isolation of resources and billing (AWS Organizations, later).

Exam cheat-sheet

  • Full, unrestricted access, created with the account→Root user
  • Close the account / change root email→Root-only task
  • Only IAM admin locked themselves out→Root restores permissions
  • First thing to do after creating an account→Secure root with MFA, create an admin identity
  • Root access keys?→Don't create them

Check yourself

Answer out loud before you open each card.

How many root users does an AWS account have?Show answer

Exactly one.

Can an IAM user belong to two AWS accounts?Show answer

No. An IAM user lives in exactly one account. (Cross-account access uses roles.)

Name two tasks that require the root user.Show answer

Any two of: close the account, change the account email or root password, restore a locked-out admin's permissions, enable IAM access to billing, S3 MFA Delete, RI Marketplace seller.

Launching an EC2 instance: root or IAM user?Show answer

IAM user (or role). It's an everyday task.

The CI bot's key leaked. What stays unaffected when you revoke it?Show answer

The account, the root user and every other IAM user.

Why do companies use several AWS accounts?Show answer

Isolation: separate resources, permissions and bills for dev, test and prod or per team.
