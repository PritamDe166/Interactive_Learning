Launching a web server with user data

  • User data is a script you paste at launch. It runs once, at the first boot, as root: perfect for installing a web server.
  • An instance moves through states: pending → running → stopping → stopped, and shutting-down → terminated.
  • Stop: compute billing ends, the EBS disk is kept, and the public IP is released (you get a new one on start).
  • Terminate is permanent: the instance and (by default) its root volume are deleted.

Points to remember

  1. User data = bootstrap script in "Advanced details" at launch. Runs only once, at first start, with root privileges.
  2. Typical uses: install updates, install software (httpd), download files, write config. The more it does, the longer first boot takes.
  3. "Running" in the console doesn't mean user data has finished: give it a minute before testing the website.
  4. Stop → no instance (compute) charge; EBS still billed; RAM is lost; public IPv4 released; private IP kept.
  5. Start after stop → usually a new public IPv4; user data does not run again.
  6. Want a public IP that never changes? Attach an Elastic IP (billed hourly, like all public IPv4).
  7. Terminate = permanent. Root volume deleted when "delete on termination" is on (default for the root volume); extra volumes and Elastic IPs remain and keep billing.
  8. Website troubleshooting: instance running? user data finished? HTTP 80 allowed? using http:// not https? current public IP?

Exam cheat-sheet

  • Configure instances automatically at first launch→EC2 user data
  • User data runs as…→root, once
  • Public IP changed after restart→Normal; use an Elastic IP to keep one
  • Stopped instance still costs money→EBS storage (and Elastic IP)

Check yourself

You stop and start an instance. Does user data run again?Show answer

No. It runs only at the first launch.

Why did your bookmark stop working after a restart?Show answer

The public IPv4 changed. The private IP stays; use an Elastic IP or DNS name for a stable address.

What happens to the root EBS volume when you terminate?Show answer

Deleted, if "delete on termination" is enabled (the default for root volumes).
