AWS CLF-C02 / Amazon S3 / 2 · Domain 2 Security

S3 Security & Bucket Policies

  • Buckets are private by default. Access is granted by IAM policies (on users and roles) or a bucket policy (on the bucket).
  • A request is allowed if either policy allows it and no policy explicitly denies it.
  • Block Public Access is on by default and overrides any public grant.
  • Making a bucket public needs both: Block Public Access off and a public-read bucket policy.

Points to remember

  1. Security layers: IAM policies (identity-based), bucket policies (resource-based), ACLs (legacy, disabled by default), Block Public Access, and encryption.
  2. A request is allowed if an IAM policy or the bucket policy allows it, and there is no explicit Deny. Explicit Deny always wins.
  3. Bucket policy parts: Principal, Effect, Action, Resource (and optional Condition).
  4. Use a bucket policy to grant public access, cross-account access, or to force HTTPS or encryption.
  5. Block Public Access is on by default and overrides public grants. It can be set per bucket or for the whole account.
  6. An EC2 instance that needs S3 gets an IAM role, never stored access keys.
  7. Shared responsibility: you configure policies, Block Public Access and encryption; AWS secures the service.

    2. 
        
  2. Bucket → Permissions → Block public access → Edit, untick Block all public access, confirm.
    3. 
        
  3. Bucket policy → Edit: allow s3:GetObject for Principal * on arn:aws:s3:::your-bucket/* (the AWS Policy Generator can write it).
    4. 
        
  4. Reload the Object URL: the image now opens. Turn Block Public Access back on afterwards; the URL fails again.

You add a public-read bucket policy but the URL still says AccessDenied. Why?Show answer
Block Public Access is still on, and it overrides public grants.

      
How do you let another AWS account read your bucket?Show answer
With a bucket policy naming that account (and their admin allows it in IAM).

      
An IAM policy allows a read, and the bucket policy denies it. Result?Show answer
Denied. An explicit Deny always wins.

      
An app on EC2 needs to upload to S3. What is the best practice?Show answer
Attach an IAM role to the instance.

      
What are the four main elements of a bucket policy statement?Show answer
Principal, Effect, Action, Resource (plus an optional Condition).

      
Who is responsible for a bucket being accidentally public?Show answer
The customer. Configuring access is your side of the shared responsibility model.
