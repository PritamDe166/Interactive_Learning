Elastic Load Balancing & Auto Scaling

  • Load balancer (ELB): one entry point that spreads traffic and skips unhealthy targets.
  • Auto Scaling group (ASG): decides how many instances run, between a min and a max, and replaces failed ones.
  • Together, across two or more AZs, they give high availability and elasticity.
  • The ideas behind them are in System Design: scaling, proxies and load balancers, algorithms.

Exam cheat-sheet

  • Survive an AZ failure→Multi-AZ ASG + load balancer
  • Add/remove instances automatically with demand→Auto Scaling (elasticity)
  • Replace failed instances automatically→Auto Scaling group
  • HTTP path/host routing→ALB
  • Static IP, TCP/UDP, extreme performance→NLB
  • Third-party firewall appliances→GWLB

How ELB and ASG connect

The ALB sends traffic to a target group. The ASG registers new instances in that group and deregisters ones it removes. ELB health checks can tell the ASG to replace an instance that the ALB found unhealthy.

What ELB adds

One DNS name, health checks, TLS termination with ACM certificates, AWS WAF on ALB, Route 53 alias records, and it scales itself. AWS runs it; you configure listeners, target groups and security groups.

What it costs

ELB: per hour plus capacity units (LCU / NLCU / GLCU). EC2 Auto Scaling: no extra charge; you pay for the instances, EBS and CloudWatch it uses. Mix Spot and On-Demand in one group.

Corrected

The Classic Load Balancer isn't retired. It's the previous generation, still documented and billed; AWS recommends migrating to ALB or NLB.

Corrected

ELB + ASG don't deliver "agility". They deliver high availability and elasticity. Agility is the general cloud benefit of getting resources in minutes instead of weeks.

Updated

Use launch templates. Launch configurations are deprecated; accounts created since 1 October 2024 can't create them. The hands-on's Amazon Linux 2 reached end of support on 30 June 2026 (use AL2023).

Added

HA vs DR: multi-AZ (ASG + ELB) survives a data-centre failure; multi-Region is disaster recovery and lower latency for distant users, covered in Global Infrastructure. A single-AZ ASG is not highly available.

Check yourself

Answer out loud before you open each card.

min 2, desired 4, max 6. Traffic triples. How many instances at most?Show answer

6. The ASG never goes above max, even if CPU stays high.

Which load balancer gives you a static IP?Show answer

Network Load Balancer (one static or Elastic IP per AZ). ALB gives a DNS name only.

Traffic peaks every weekday at 9 am. Which two methods scale ahead of it?Show answer

Scheduled (you set the time) and predictive (ML learns the pattern).

Which service replaces a failed EC2 instance automatically: ELB or ASG?Show answer

Auto Scaling group. ELB only stops sending traffic to it.

You must route traffic through third-party firewall appliances. Which load balancer?Show answer

Gateway Load Balancer (layer 3, GENEVE on port 6081).

"Automatically add and remove capacity as demand changes": which cloud term?Show answer

Elasticity. Scalability is the ability to grow; agility is speed of provisioning.
