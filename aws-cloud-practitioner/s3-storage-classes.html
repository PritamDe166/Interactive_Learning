AWS CLF-C02 / Amazon S3 / 6 · Domain 3 Technology

S3 Storage Classes & Lifecycle

  • Every class has 11 nines of durability; they differ in price, availability, retrieval time and fees, and minimum duration.
  • Standard for frequent access, Standard-IA / One Zone-IA for infrequent, three Glacier classes for archives.
  • Intelligent-Tiering moves objects automatically when the access pattern is unknown.
  • Lifecycle rules move objects to cheaper classes as they age and delete them at the end.

Points to remember

  1. Durability is 11 nines for every class; availability differs (Standard 99.99%, IA 99.9%, One Zone-IA 99.5%).
  2. Standard: frequent access, default. Standard-IA: infrequent, instant, retrieval fee, 30-day minimum.
  3. One Zone-IA: one AZ, cheaper, for re-creatable data.
  4. Glacier Instant Retrieval (ms, 90 days), Glacier Flexible Retrieval (minutes to hours, 90 days), Glacier Deep Archive (cheapest, within 12 hours, 180 days).
  5. Intelligent-Tiering: automatic tiering by access, small monitoring fee, no retrieval fees.
  6. Express One Zone: single-digit ms, one AZ, directory bucket.
  7. Lifecycle rules: transition actions (move to another class after N days) and expiration actions (delete after N days, including old versions).

In the console

Change a storage class and add a lifecycle rule (outline)
  1. Upload an object and choose its storage class under Properties (for example Standard-IA).
  2. Select an existing object → Actions → Edit storage class to move it to Glacier Instant Retrieval.
  3. Bucket → Management → Create lifecycle rule: transition current versions to Standard-IA after 30 days and Glacier Flexible Retrieval after 90; expire after 2,555 days.
  4. Review the timeline the console draws, then save.

Cheat-sheet

  • Frequent access, default→S3 Standard
  • Unknown or changing access pattern→Intelligent-Tiering
  • Infrequent, instant, multi-AZ→Standard-IA
  • Infrequent, re-creatable, cheaper→One Zone-IA
  • Archive, needs milliseconds→Glacier Instant Retrieval
  • Archive, minutes to hours is fine→Glacier Flexible Retrieval
  • Cheapest, 12 hours is fine→Glacier Deep Archive
  • Lowest latency, next to compute→Express One Zone
  • Move objects by age automatically→Lifecycle rules

Minimum duration. Delete or move an object before its minimum and you still pay for the full minimum (for example 90 days in Glacier Flexible Retrieval).

Lifecycle vs Intelligent-Tiering. Lifecycle rules move data by age on a schedule you set; Intelligent-Tiering moves it by actual access, object by object.

Glacier retrieval options. Flexible Retrieval offers expedited (minutes), standard (hours) and free bulk retrievals (up to about 12 hours).

Is durability lower in One Zone-IA?Show answer

Durability is still designed for 11 nines, but data is in one AZ, so losing that AZ loses the data; availability is 99.5%.

What happens if you delete a Standard-IA object after 10 days?Show answer

You are billed for the 30-day minimum.

A lifecycle rule (transition action).
