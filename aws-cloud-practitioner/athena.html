AWS CLF-C02 / Databases & analytics / 9 · Domain 3 Technology

Amazon Athena

  • Athena runs SQL directly on files in S3: no loading, no servers.
  • Tables over the files are defined in the Glue Data Catalog.
  • You pay per data scanned: $5 per TB.
  • Compression, columnar formats (Parquet, ORC) and partitions cut both cost and time.

In terms you know

AWSClosest thing you knowThe difference
AthenaSQL Server PolyBase or OPENROWSET over a folder of CSV filesServerless and billed per query, not per server.

Walkthrough: querying load balancer logs in S3

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Athena = serverless, interactive SQL on S3 (CSV, JSON, ORC, Avro, Parquet).
  2. Priced at $5 per TB scanned.
  3. Save money: compress, use columnar formats (Parquet/ORC), partition data.
  4. Uses the Glue Data Catalog for table metadata; results land in S3.
  5. Typical: analysing VPC Flow Logs, ELB logs, CloudTrail logs; BI with QuickSight.
  6. Federated queries can reach other sources (databases, on-premises) through connectors.

Compression is assumed at 4×. Only Parquet lets Athena skip unused columns; only partitions let it skip unused dates.

Cheat-sheet

  • Query S3 with SQL, serverless, ad hoc→Athena
  • Athena price basis→Data scanned ($5 per TB)
  • Cut Athena cost→Compress, Parquet/ORC, partition
  • Analyse VPC Flow Logs or CloudTrail logs→Athena
  • Table definitions for Athena→Glue Data Catalog
