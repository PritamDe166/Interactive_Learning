EC2 Basics

  • EC2 (Elastic Compute Cloud) rents you virtual servers called instances. It's IaaS.
  • You pick the AMI (OS image), instance type (CPU, memory), storage and security group (firewall).
  • An optional user data script sets the machine up on first boot.
  • Around it sit EBS volumes, load balancers and Auto Scaling groups.

In .NET / Azure terms

If you've run an app on an Azure VM or your own IIS server, EC2 is the same idea with AWS names.

Exam cheat-sheet

  • "Rent a virtual server" / IaaS compute→EC2
  • Request times out→Check the security group
  • Connection refused→App not listening; SG is fine
  • Script that installs software at first launch→User data
  • Linux admin port / Windows admin port→22 (SSH) / 3389 (RDP)
  • Keep the same public IP after stop/start→Elastic IP

Connecting and the ports to know

SSH / PuTTY

Your terminal (macOS, Linux, Windows 10+) or PuTTY on Windows, with the key pair's private key (.pem for OpenSSH, .ppk for PuTTY). Needs inbound port 22. Windows instances use RDP, port 3389.

EC2 Instance Connect

SSH in the browser. AWS pushes a temporary key, so you don't handle one. It's still SSH, so port 22 must be open (from AWS's Instance Connect range, or through an Instance Connect Endpoint for private instances).

Session Manager

Shell through the SSM agent and an IAM role: no port 22, no keys, no bastion, every session logged. Covered in Deployment & IaC.

Added

Security groups are stateful. If a request is allowed in, the reply goes out automatically (and vice versa), whatever the other direction's rules say. Network ACLs, at the subnet level, are stateless and can deny; they come in the VPC section.

Corrected

r5.16xlarge has 64 vCPUs and 512 GiB, not 16 vCPUs. Each size step doubles the resources: 4xlarge = 16 vCPUs, 8xlarge = 32, 16xlarge = 64. c5.4xlarge (16 vCPU, 32 GiB) and t2.micro (1 vCPU, 1 GiB) are right.

Updated

The lab's choices have aged. Amazon Linux 2 reached end of support on 30 June 2026: use Amazon Linux 2023 (which uses dnf, hence the script above). New root volumes default to gp3, not gp2. Accounts created since 15 July 2025 get a credit-based free plan (up to $200, 6 months) and micro types such as t3.micro / t4g.micro, not t2.micro. Always check the console.

Added

Accelerated computing is the fifth family your notes didn't list: GPUs or custom chips (P, G, Inf, Trn) for ML training, inference and graphics. Apps on EC2 that call AWS APIs should use an IAM role, never stored access keys.

Check yourself

Answer out loud before you open each card.

In c7g.4xlarge, what do c, 7, g and 4xlarge mean?Show answer

Compute optimized family, 7th generation, Graviton (Arm) processor, size 4xlarge (16 vCPUs).

Your browser shows a timeout on port 80. First thing to check?Show answer

The security group's inbound rule for port 80. A timeout means traffic didn't arrive.

Can a security group contain a deny rule?Show answer

No. Allow rules only; anything not allowed is blocked. (Network ACLs can deny.)

You stop and start an instance. Does user data run again, and is the public IP the same?Show answer

No and usually no. User data runs only on first boot; the public IPv4 changes unless you attach an Elastic IP.

Which family for an in-memory cache with a huge working set?Show answer

Memory optimized (R, X families).

Which port do you open to manage a Windows instance remotely?Show answer

3389 (RDP). Port 22 is SSH for Linux.
