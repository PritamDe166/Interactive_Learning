AWS CLF-C02 / Amazon S3 / Section review

Amazon S3: review

  • S3 stores objects in Regional buckets with globally unique names; 11 nines of durability.
  • Access: IAM policies, bucket policies, Block Public Access; explicit Deny wins. Encrypted at rest by default (SSE-S3).
  • Versioning protects against deletes and overwrites; replication (CRR/SRR) copies to other buckets.
  • Storage classes and lifecycle rules cut cost; Storage Gateway connects on-premises servers.

Section summary

Buckets & objects

  • Object storage, virtually unlimited; max object ~48.8 TiB.
  • Bucket in one Region; name unique globally.
  • Key = prefix + name; no real folders.
  • Pre-signed URL for temporary access.

Security

  • Private by default.
  • Allowed if IAM or bucket policy allows and nothing denies.
  • Public = BPA off + public bucket policy.
  • Access Analyzer finds public and cross-account buckets.

Website, versioning, replication

  • Static website: HTTP endpoint, index document; 403 = not public; CloudFront for HTTPS.
  • Versioning: delete marker, permanent version delete, every version billed.
  • Replication: versioning on both, async, not retroactive; CRR vs SRR.

Classes, encryption, hybrid

  • Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier Instant / Flexible / Deep Archive, Express One Zone.
  • Lifecycle: transitions and expiration.
  • SSE-S3 default, SSE-KMS audited, SSE-C, client-side.
  • Storage Gateway: File, Volume, Tape.

Commonly confused pairs

PairThe difference
S3 vs EBS vs EFSObject storage over HTTPS vs a block disk for one instance vs a shared NFS file system
Bucket policy vs IAM policyAttached to the bucket (can name other accounts or everyone) vs attached to a user or role
Block Public Access vs bucket policyA safety override that stops public grants vs the grant itself
Versioning vs replicationOlder versions inside one bucket vs copies in another bucket (needs versioning)
CRR vs SRRCopy to another Region vs another bucket in the same Region
Standard-IA vs One Zone-IAMulti-AZ, 99.9% vs one AZ, 99.5%, for re-creatable data
Glacier Instant vs Flexible vs Deep ArchiveMilliseconds vs minutes to hours vs within 12 hours (cheapest)
Intelligent-Tiering vs lifecycle rulesMoves objects by actual access vs by age on your schedule
SSE-S3 vs SSE-KMSS3 manages the keys (default) vs you control keys in KMS with CloudTrail audit
Storage Gateway vs DataSync / SnowballOngoing hybrid access vs moving data once

Section cheat-sheet

  • Object storage, virtually unlimited→S3
  • Recover deleted or overwritten objects→Versioning
  • Copy to another Region→CRR (needs versioning)
  • Aggregate logs in the same Region→SRR
  • Unknown access pattern→Intelligent-Tiering
  • Infrequent, instant, multi-AZ→Standard-IA
  • Archive in milliseconds→Glacier Instant Retrieval
  • Cheapest archive→Glacier Deep Archive
  • Prevent public exposure→Block Public Access
  • Cross-account or public grant→Bucket policy
  • Encrypted at rest by default→SSE-S3
  • HTTPS for an S3 website→CloudFront
  • On-premises access to S3→Storage Gateway
