Amazon EKS

  • EKS is managed Kubernetes on AWS.
  • AWS runs the control plane; pods run on EC2 nodes or on Fargate.
  • Kubernetes is open source and cloud-agnostic: good for portability and hybrid setups.

In terms you know

AWSClosest thing you knowThe difference
EKSAn on-premises Kubernetes cluster whose master nodes someone else operatesAWS keeps the control plane available and patched.

Walkthrough: Kubernetes without running the masters

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. EKS = Elastic Kubernetes Service: managed Kubernetes clusters.
  2. Kubernetes deploys, scales and manages containers, which run as pods.
  3. Control plane managed by AWS; workers on EC2 (you) or Fargate (serverless).
  4. Use for existing Kubernetes, multi-cloud or hybrid portability.
  5. Exam trigger: "Kubernetes" → EKS.

EKS or ECS?

Pick the orchestrator

Cheat-sheet

  • Kubernetes→EKS
  • AWS-native container orchestration→ECS
  • Kubernetes pods without nodes→EKS on Fargate
  • Portable across clouds→Kubernetes / EKS
