Amazon CloudFront

  • CloudFront is AWS's content delivery network (CDN).
  • It caches content at edge locations near users, so repeat requests are fast.
  • Origins: S3 (private with OAC), ALB/EC2, any HTTP server.
  • Built-in DDoS protection (Shield Standard) and optional WAF.

In terms you know

AWSClosest thing you knowThe difference
CloudFrontAkamai or Azure Front Door/CDN in front of your IIS siteIntegrated with S3, ALB, Shield and WAF.

Points to remember

  1. CloudFront = CDN: improves read performance by caching at edge locations.
  2. Hundreds of edge locations worldwide.
  3. Origins: S3 (with origin access control), ALB, EC2, any HTTP backend.
  4. DDoS protection with Shield; can attach WAF.
  5. Great for static content; also accelerates dynamic content.
  6. Different from S3 CRR: cache with TTL at many edges vs full copy in one Region.

Cheat-sheet

  • Cache content near users worldwide→CloudFront
  • HTTPS for an S3 website→CloudFront
  • Keep S3 private behind the CDN→Origin access control
  • Copy a whole bucket to another Region→S3 CRR, not CloudFront
