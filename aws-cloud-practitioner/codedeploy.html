AWS CLF-C02 / Deployment & infrastructure / 8 · Domain 3 Technology

AWS CodeDeploy

  • CodeDeploy deploys new versions to EC2 instances and on-premises servers (also Lambda and ECS).
  • It is hybrid: a CodeDeploy agent on each server pulls and installs the new version.
  • Servers must already exist; CodeDeploy only upgrades the app.

In terms you know

AWSClosest thing you knowThe difference
CodeDeployOctopus Deploy or Azure DevOps release pipelines with deployment agentsAWS-managed; agents on EC2 or your own servers.

Walkthrough: the clinic API's path from commit to servers

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CodeDeploy = automated application deployments to EC2, on-premises servers, Lambda and ECS.
  2. Hybrid: works on-premises too.
  3. Needs the CodeDeploy agent on each server (your task) and servers that already exist.
  4. In-place or blue/green deployments; automatic rollback on failure.
  5. Independent of CloudFormation and Beanstalk.
