AWS CodeBuild

  • CodeBuild compiles code, runs tests and produces packages: a fully managed, serverless build service.
  • Steps are defined in a buildspec.yml file.
  • You pay only for build minutes; no build servers to run.

In terms you know

AWSClosest thing you knowThe difference
CodeBuildAn Azure DevOps hosted agent or a Jenkins build agentNothing to install or keep running.

Walkthrough: the clinic API's path from commit to servers

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. CodeBuild = fully managed, serverless build service: compile, test, package.
  2. Instructions in buildspec.yml.
  3. Pay per build minute; scales automatically.
  4. Outputs artifacts to S3/ECR, logs to CloudWatch.
  5. Usually started by CodePipeline or a webhook.

Cheat-sheet

  • Build and test code, serverless→CodeBuild

  • Build instructions file→buildspec.yml
