EC2 Purchasing Options

  • Same instance, different price models: you trade flexibility for discount.
  • On-Demand: no commitment, full price.
  • Reserved Instances / Savings Plans: commit for 1 or 3 years, save up to ~72%.
  • Spot: spare capacity, up to ~90% off, but AWS can take it back.
  • Dedicated and Capacity Reservations solve isolation and capacity, not price.

Resort analogy

On-Demand = walk in, full price. Reserved = book a specific room for a year. Savings Plan = commit to spend $X/night, any room. Spot = last-minute deal, can be bumped. Dedicated Host = rent the whole building. Capacity Reservation = pay to hold a room even if you don't come.

Host vs Instance

Both keep other customers off your hardware. Only a Dedicated Host gives you the whole physical server, visibility of sockets and cores, and control over placement: that's what per-core licences (Oracle, Windows Server) need.

Who patches what?

Pricing doesn't change the split: AWS runs the hosts, you run the OS, software, security groups and data. See Shared Responsibility.

Added

Spot gives a 2-minute interruption notice (via instance metadata and EventBridge). Use it to checkpoint and drain. Spread Spot across many instance types and AZs (EC2 Fleet / Auto Scaling mixed instances) to lower the chance of losing everything at once.

Updated

You don't "bid" for Spot any more. You pay the current Spot price, which moves slowly; interruptions happen mainly when AWS needs the capacity back. A maximum price is optional and defaults to the On-Demand price.

Added

Only Standard RIs can be sold on the Reserved Instance Marketplace; Convertible RIs can't. AWS now generally recommends Savings Plans over RIs for EC2 because they apply automatically across sizes, OSs and (Compute SP) services.

Added

Discount percentages are AWS's "up to" figures and vary by instance type, Region, term and upfront payment. The exam tests the ranking (Spot > RI ≈ Savings Plans > On-Demand), not exact numbers.

Check yourself

Answer out loud before you open each card.

A database must run 24/7 for the next 3 years. Cheapest suitable option?Show answer

3-year Reserved Instance (All Upfront for the deepest discount), or an EC2 Instance Savings Plan.

Nightly batch jobs that can restart. Which option?Show answer

Spot Instances. Up to ~90% cheaper; design the job to checkpoint and retry.

Your licence is billed per physical CPU core. What do you need?Show answer

Dedicated Host: it exposes sockets and cores and lets you control placement (BYOL).

Does a Capacity Reservation give a discount?Show answer

No. It guarantees capacity in one AZ at On-Demand price, charged even if you launch nothing.

You'll move part of your EC2 workload to Fargate and Lambda next year. Which commitment still applies?Show answer

Compute Savings Plan: it covers EC2 (any family, Region, OS), Fargate and Lambda.

Standard vs Convertible RI: what do you trade?Show answer

Convertible lets you exchange to a different family, OS or tenancy, for a smaller discount.
