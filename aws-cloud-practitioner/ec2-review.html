EC2: review

  • EC2 rents virtual servers (IaaS): AMI + instance type + storage + security group + key pair + user data.
  • Requests reach the public IP, pass the security group (stateful, allow-only), and hit the software on the instance.
  • Get in with SSH 22, Instance Connect or RDP 3389; give the instance AWS access with an IAM role.
  • Pay with On-Demand, Reserved, Savings Plans, Spot, Dedicated or Capacity Reservations, and set a budget first.

Section summary

Budgets

  • AWS Budgets emails on actual or forecasted cost/usage.
  • Zero-spend and monthly cost budgets.
  • Root activates IAM access to billing.
  • EBS, public IPv4, NAT Gateway bill too.

EC2 basics & user data

  • IaaS; AMI, type, storage, SG, key pair, user data.
  • User data: once, first boot, as root.
  • Stop: EBS kept, new public IP on start. Terminate: gone, root EBS deleted.
  • Elastic IP keeps a fixed public IPv4.

Instance types

  • m5.2xlarge = family · generation · size.
  • General (T, M) · Compute (C) · Memory (R, X) · Storage (I, D, H) · Accelerated (P, G).

Security groups

  • Allow-only, stateful; inbound blocked, outbound allowed by default.
  • Sources: CIDR or another SG; Region/VPC scoped; many-to-many.
  • Timeout = SG; refused = app. Ports 21, 22, 80, 443, 3389.

Connecting & roles

  • SSH 22 with .pem (chmod 400, ec2-user); PuTTY .ppk; RDP 3389 for Windows.
  • Instance Connect: browser, temporary key, still port 22.
  • IAM role via instance profile; never aws configure with your keys.

Purchasing & responsibility

  • On-Demand · Reserved (1/3 yr, ~72%) · Convertible · Savings Plans ($/h) · Spot (~90%, interruptible) · Dedicated Host (BYOL) · Dedicated Instance · Capacity Reservation (no discount).
  • You: SG rules, OS patches, software, IAM roles, data. AWS: hardware, host isolation, network.

Commonly confused pairs

PairThe difference
Stop vs terminateStop keeps EBS and lets you start again (new public IP); terminate deletes the instance (and root volume by default)
Public vs private IPv4Public reaches it from the internet and changes on stop/start; private is inside AWS and stays
Timeout vs connection refusedBlocked before arrival (security group) vs arrived but nothing listening (application)
Security group vs NACLInstance-level, stateful, allow-only vs subnet-level, stateless, allow and deny (VPC section)
SSH vs RDPLinux, port 22, key pair vs Windows, port 3389
Reserved Instance vs Savings PlanCommit to an instance configuration vs commit to $ per hour of compute
Standard vs Convertible RIBigger discount, fixed vs smaller discount, can change type/family
Dedicated Host vs Dedicated InstanceWhole physical server with host visibility (BYOL) vs hardware not shared with other customers, no host control
Capacity Reservation vs Reserved InstanceCapacity guarantee in one AZ, no discount vs discount for a 1/3-year commitment
Spot vs On-DemandUp to ~90% cheaper but interruptible vs full price, never interrupted by AWS

Section cheat-sheet

  • Virtual servers, you manage the OS→EC2 (IaaS)
  • Configure an instance automatically at first boot→User data
  • Instance firewall→Security group
  • Linux admin / Windows admin→SSH 22 / RDP 3389
  • App on EC2 needs AWS access→IAM role
  • Steady 24/7 workload for 3 years→Reserved Instance / Savings Plan
  • Interruptible batch, cheapest→Spot
  • Per-socket licences, compliance→Dedicated Host
  • Guaranteed capacity in one AZ→Capacity Reservation
  • Short, unpredictable, no interruptions→On-Demand
  • Email when spend passes a threshold→AWS Budgets
  • Patching the EC2 guest OS→Customer
