AWS CLF-C02 / Databases & analytics / 10 · Domain 3 Technology

Amazon QuickSight

  • QuickSight is serverless business intelligence: interactive dashboards and charts.
  • It connects to RDS, Aurora, Redshift, Athena, S3 and more.
  • It adds ML-powered insights (anomalies, forecasts) and can be embedded in your apps.
  • In the current exam guide it is written "Amazon Quick Sight".

In terms you know

AWSClosest thing you knowThe difference
QuickSightPower BI or SSRS dashboardsFully managed on AWS; no report server to run.

Walkthrough: a bookings dashboard for clinic managers

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. QuickSight = serverless BI: dashboards, visualisations, reports.
  2. Sources: RDS, Aurora, Athena, Redshift, S3, and third-party databases.
  3. ML insights: anomaly detection, forecasting, natural-language questions.
  4. Dashboards can be shared and embedded; per-user security.
  5. Query engines (Athena, Redshift) find answers; QuickSight visualises them.

Cheat-sheet

  • Dashboards, BI, visualise data→QuickSight
  • Charts embedded in a web app→QuickSight embedding
  • Query the data→Athena or Redshift
  • Prepare the data→Glue
