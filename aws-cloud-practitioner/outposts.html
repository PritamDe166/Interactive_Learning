AWS CLF-C02 / Global infrastructure / 6 · Domain 3 Technology

AWS Outposts

  • Outposts puts AWS-managed racks or servers in your own data centre.
  • Same AWS services, APIs and console on-premises: a consistent hybrid cloud.
  • For low latency to local systems, local data processing and data residency.
  • You are responsible for the physical security of the Outpost.

In terms you know

AWSClosest thing you knowThe difference
OutpostsAzure Stack, or a vendor-managed private cloud in your server roomRun by AWS and connected to a Region.

Walkthrough: bringing AWS into a hospital

Use Next ▶ to go one step at a time, or Play all

Points to remember

  1. Outposts = server racks with the same AWS infrastructure, services, APIs and tools, in your data centre.
  2. AWS sets up and manages them; you get a consistent hybrid experience.
  3. Benefits: low-latency access to on-premises systems, local data processing, data residency, easier migration.
  4. Services include EC2, EBS, S3, RDS, ECS, EKS, EMR.
  5. Customer is responsible for physical security of the Outposts rack.
