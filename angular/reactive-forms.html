Reactive forms & Signal Forms

  • In a reactive form you build the form model in the class (FormGroup, FormControl), then bind the template to it.
  • Validators are functions (Validators.required), so rules live in TypeScript where you can test them.
  • Forms are typed: getRawValue() returns { name: string; … }.
  • valueChanges is an Observable; toSignal() turns it into a signal for the template.
  • New: Signal Forms (form() + [formField]) wrap a signal you own; every state is a signal.

Cheat-sheet

  • Build a form in the class→inject(NonNullableFormBuilder).group({ name: ['', Validators.required] })
  • Bind it→ReactiveFormsModule, <form [formGroup]="form">, formControlName="name"
  • Show all errors on submit→form.markAllAsTouched()
  • Typed, complete value→form.getRawValue() (.value skips disabled controls, so fields may be undefined)
  • React to changes in the template→toSignal(form.valueChanges, { initialValue: form.getRawValue() })
  • Starting fresh, want signals end to end→form(signal(model), p => { required(p.name) }) + [formField]

Updated

Typed forms. Your notes' FormGroup / FormControl pages predate typed forms (v14+). In CareDesk, const n: string = this.form.value.name failed with TS2322: Type 'string | undefined' is not assignable to type 'string', while getRawValue() is fully typed.

Added

Signal Forms in Angular 22. Introduced as experimental in v21 and promoted in v22 (see the v22 release notes), @angular/forms/signals exports form, FormField, required, minLength, pattern and submit. In the real run, errors came back as objects with a kind such as 'required' or 'minLength', and submitting an empty form did not mark fields touched, so show errors on submit yourself.

Added

Typos fail at runtime here. formControlName="phon" built fine and threw when the page opened: NG01055: Cannot find control with path: 'phon'. Controls that do exist at this level: name, department, triage, phone.

Check yourself

Answer out loud before you open each card.

Biggest difference between template-driven and reactive?Show answer

Where the form model is created: implicitly by directives in the template, or explicitly in the class. Reactive forms put structure and rules in TypeScript, which is easier to test and to change dynamically.

Why NonNullableFormBuilder?Show answer

With it, reset() returns controls to their initial value instead of null, so the types stay string rather than string | null.

form.value vs form.getRawValue()?Show answer

value excludes disabled controls, so each field is typed as possibly undefined. getRawValue() includes everything with exact types.

How did CareDesk show errors after clicking Register on an empty form?Show answer

markAllAsTouched() in save(), so "Name is required" and "Pick a department" appeared even for fields never visited.

How does the live preview update?Show answer

toSignal(this.form.valueChanges, …) turns the Observable into a signal, which the template reads like any other signal.

In Signal Forms, where's the data?Show answer

In your own signal<NewPatient>. form(model, schema) doesn't copy it: typing "Kiran" updated model() directly.
