Routing

  • The router maps the URL to a component and renders it in <router-outlet />, without reloading the page.
  • Routes are checked top to bottom; the first match wins. Put '**' last.
  • routerLink navigates inside the app; href reloads everything.
  • URL parameters such as :id can arrive as a component input (withComponentInputBinding).
  • loadComponent lazy-loads a page: its code downloads on first visit.

Cheat-sheet

  • Default page→{ path: '', redirectTo: 'patients', pathMatch: 'full' }
  • Page with a parameter→{ path: 'patients/:id', … } + id = input.required<string>()
  • Link in a template→routerLink="/patients" or [routerLink]="['/patients', p.id]"
  • Navigate from code→inject(Router).navigate(['/patients'])
  • Highlight the current link→routerLinkActive="active", add [routerLinkActiveOptions]="{ exact: true }" for parents
  • Big page used rarely→loadComponent: () => import('./x').then(m => m.X)
  • Unknown URL→{ path: '**', component: NotFound }, always last

Corrected

routerLinkActiveOptions needs square brackets. Your notes write it as a plain attribute. Without brackets the value is the string "{ exact: true }", and the CareDesk build failed: TS2322: Type '"{ exact: true }"' is not assignable to type '{ exact: boolean; } | Partial<IsActiveMatchOptions> | …'. Also, it's routerLinkActive (camel case).

Corrected

What pathMatch: 'full' means. The notes say it makes the router find a full match for home. It applies to the empty path itself: redirect only when the whole URL is empty. Every URL starts with an empty prefix, so without it the route would match everything; Angular refuses that configuration (NG04014).

Updated

No routing module. The notes' AppRoutingModule with RouterModule.forRoot(routes) is replaced by app.routes.ts plus provideRouter(routes) in app.config.ts. Components import RouterOutlet, RouterLink, RouterLinkActive themselves.

Added

Route titles and parameters as inputs. title on a route set the browser tab ("Patient · CareDesk" on /patients/2). withComponentInputBinding() passed :id straight into id = input.required<string>(). URL values are always strings: convert with Number().

Check yourself

Answer out loud before you open each card.

How does the router choose a route?Show answer

It checks the routes in array order and takes the first whose path matches the URL. Order matters: specific before general, '**' last.

'**' was put first. What happened?Show answer

Every URL, including / and /patients/2, showed "Page not found" in the real run.

href="/patients" vs routerLink="/patients"?Show answer

href made the browser reload the app (main.js was downloaded again and all state reset). routerLink swapped the component in place with no downloads.

What does lazy loading change?Show answer

PatientDetail's code moved into a separate chunk (chunk-FPJUGB3L.js) that downloaded only when the first patient link was clicked, keeping the first load smaller.

Why is id a string input?Show answer

Everything in a URL is text. Convert it (Number(this.id())), and handle ids that don't exist: /patients/99 showed "No patient with id 99."

Why did "Waiting room" lose its active style on /patients/2?Show answer

{ exact: true }. Without it the link counts as active for any URL that starts with /patients; in the real run it stayed active on the detail page.
