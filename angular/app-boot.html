How an Angular app boots

  • Node.js and the Angular CLI are build tools on your machine. The app itself runs in the browser.
  • ng new creates the workspace; ng serve compiles TypeScript and templates into JavaScript and serves it.
  • The browser first gets an almost empty index.html: just <app-root></app-root> and a script tag.
  • main.ts calls bootstrapApplication(App, appConfig). appConfig lists app-wide providers. There's no NgModule.
  • Angular finds <app-root>, creates App and renders its template inside it.

Corrected
"Angular uses Node.js on the server side." Node is only needed on your machine (and in CI) to run the CLI, the dev server and the build. The built app is plain JavaScript, HTML and CSS that runs in the browser and can be hosted anywhere static, such as S3, Azure Static Web Apps or IIS. (Server-side rendering is an optional extra.)

      
Corrected
Install steps had no commands. They are: install Node.js (Angular 22 needs Node 22.22+, 24.15+ or 26+), then npm install -g @angular/cli, ng new caredesk, cd caredesk, ng serve --open (opens http://localhost:4200).

      
Updated
No app.module.ts any more. Your notes' structure had app.module.ts with declarations and imports. Since v17 new projects are standalone: each component lists what it uses in its own imports, and app-wide services go in app.config.ts. The CLI also dropped the .component suffix: app.ts holds class App.

      
Added
Zoneless by default. CareDesk was created without zone.js: Angular updates the screen when signals change or template events fire, not by patching every browser API. More on the Change detection page.

      
Added
HttpClient no longer needs provideHttpClient() to be injected. In the real project, inject(HttpClient) worked with the default config. You still add provideHttpClient(...) when you want options such as interceptors (Guards & login page).

    

  


  

    
Check yourself

    
Answer out loud before you open each card.

    

      
What's the first TypeScript file that runs?Show answer
        
src/main.ts (set as the entry point in angular.json). It calls bootstrapApplication(App, appConfig).

      
How does Angular know where to draw App?Show answer
        
App's selector: 'app-root' is matched against index.html. Angular renders App's template inside that element. No match → NG05104 and a blank page.

      
What goes in appConfig.providers?Show answer
        
App-wide services and features: provideRouter(routes), provideHttpClient(withInterceptors(...)), error listeners. They form the root injector every component can inject from.

      
Does a deployed Angular app need Node.js on the server?Show answer
        
No. ng build produces static files in dist/. Any static host works. Node is needed only for building, or if you choose server-side rendering.

      
Constructor or ngOnInit: which logged first in CareDesk?Show answer
        
The constructor, then ngOnInit, then afterNextRender once the DOM was painted, and finally the bootstrap promise resolved.

      
A typo in a template: build error or runtime error?Show answer
        
Build error. Templates are compiled ahead of time and type-checked: TS2551: Property 'titel' does not exist on type 'App'. Did you mean 'title'?
