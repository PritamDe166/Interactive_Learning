TypeScript for Angular

  • TypeScript is JavaScript plus types. Types are checked when you build, then erased: the browser runs plain JavaScript.
  • An interface describes the shape of data, like a C# DTO without behaviour.
  • Union types ('routine' | 'urgent') and optional fields (phone?) catch whole classes of bugs.
  • Generics appear everywhere in Angular: signal<Patient[]>, input<Patient>, output<string>.
  • Angular checks templates with the same types, so a typo in HTML fails the build.

      Cheat-sheet

      • Shape of data from an API→interface Patient { ... } (or type); no class needed
      • A field with a fixed set of values→union of literals: type Triage = 'routine' | 'urgent'
      • A field that may be missing→phone?: string, then read it with p.phone?.length or check first
      • TS2564 "has no initializer"→give a default, make it optional (?), or in Angular use input.required()
      • Tempted to write any→use unknown and narrow it; any switches checking off
      • Member only the template uses→protected (what ng new generates for title)

      Check yourself

      Answer out loud before you open each card.

      Does interface Patient exist when the app runs?Show answer

      No. Interfaces and type annotations are erased. The emitted patient.js contains only PATIENTS and label. So data from an API isn't checked at run time; validate it if you don't trust it.

      What does triage: 'critical' give, and why?Show answer

      TS2322: Type '"critical"' is not assignable to type 'Triage'. Triage only allows the two listed strings.

      Why does p.phone.length fail to compile?Show answer

      phone is optional, so it may be undefined (TS18048). Use p.phone?.length or check if (p.phone) first.

      any vs unknown?Show answer

      any turns checking off: x.nmae.toUpperCase() compiled and crashed at run time. unknown forces you to check the type before using it (TS18046 otherwise).

      What's the <Patient[]> in signal<Patient[]>(PATIENTS)?Show answer

      A generic type argument: this signal holds an array of patients, so patients() is typed Patient[] everywhere, including templates.

      Is a typo in a template caught?Show answer

      Yes. {{ patients()[0].nmae }} failed the CareDesk build with TS2339: Property 'nmae' does not exist on type 'Patient'.
