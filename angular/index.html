Modern Angular only

Pages use what ng new gives you today: standalone components, input() / output() / model(), signals, @if / @for, functional guards and OnPush by default. Older forms appear only in "Before / After" cards.

Colour key

Cyan: data down (inputs, [property]). Orange: events up (outputs, (event)). Violet: two-way (model(), [(x)]). The same colours on every page.

One app, start to finish
