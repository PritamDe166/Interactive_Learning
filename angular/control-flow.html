Template control flow

  • Templates decide what exists with blocks: @if, @for, @switch, plus @let for local values.
  • @for needs a track expression: how Angular matches items to the DOM it already built.
  • Track by a stable id (track p.id). Tracking by $index can move state to the wrong item.
  • @empty renders when the list is empty; @else pairs with @if.
  • These replace *ngIf, *ngFor and [ngSwitch], deprecated since v20.

Cheat-sheet

    
    
      
  • Show something conditionally→@if (cond) { … } @else if (…) { … } @else { … }
    • 
      
  • Need the value you tested→@if (first(); as p) { {{ p.name }} }
    • 
      
  • Loop over items→@for (p of list(); track p.id) { … } @empty { … }
    • 
      
  • Items have an id→track p.id. No id and static list → track $index
    • 
      
  • Position, first/last, odd/even→$index, $count, $first, $last, $even, $odd
    • 
      
  • One value, several cases→@switch (x) { @case ('a') { … } @default { … } }
    • 
      
  • Reuse an expression in the template→@let total = patients().length;

Added
Not in your notes. Control flow is how every list and condition in a modern template is written, and the example in your screenshot (@if (a > b) … @else if … @else) is this syntax.

      
Updated
Deprecated, not removed. In CareDesk, a template using *ngFor and *ngIf (with NgFor, NgIf imported) still built without warnings in v22. The deprecation shows in your editor. Migrate with ng generate @angular/core:control-flow.

      
Added
Angular warns about bad tracking. With track p and freshly fetched objects, the browser console showed NG0956: The configured tracking expression (track by identity) caused re-creation of the entire collection of size 3.

    

  


  

    
Check yourself

    
Answer out loud before you open each card.

    

      
What does track do in @for?Show answer
        
It gives each item an identity so Angular can match new data to the DOM and component instances it already created: keep, move, create or destroy only what changed.

      
Why was track $index dangerous in CareDesk?Show answer
        
Discharging Asha shifted everyone up a position. The card instance at position 1, which held Asha's "Selected" state and note "needs ECG", was reused for Ravi, so Ravi showed Asha's state.

      
What's wrong with track p (the object)?Show answer
        
It works while objects keep their identity, but after a re-fetch every object is new, so every card was destroyed and recreated (NG0956) and local state was lost.

      
How do you show "No one matches"?Show answer
        
Add @empty { <p>No one matches…</p> } after the @for block.

      
Do you need to import anything for @if?Show answer
        
No. Blocks are part of the template syntax. *ngIf needed NgIf (or CommonModule) in imports.

      
What is @let for?Show answer
        
A read-only local variable in the template, e.g. @let total = patients().length;, so you don't repeat the expression.
