Data binding

  • Bindings connect a component's class to its template. Angular keeps the DOM in step for you.
  • Class → DOM (cyan): {{ value }}, [property], [class.x], [style.x], [attr.x].
  • DOM → class (orange): (event)="handler()".
  • Both ways (violet): [(ngModel)] = [ngModel] + (ngModelChange). Needs FormsModule.
  • The right-hand side is a template expression, type-checked against the class.

Corrected
The name attribute. Your notes say ngModel always needs name. Only inside a <form>, where ngForm registers each control by name. CareDesk's search box sits outside a form and works without it (forms are covered on the Template-driven forms page).

      
Corrected
Typing the handler. The notes' sendtoParentEmitter(e: any) works, but (ngModelChange) emits the new value, so type it: onSearch(text: string). With any you lose the template type check shown on the TypeScript page.

      
Updated
ngModel works with signals. [(ngModel)]="search" with search = signal('') reads and writes the signal directly; in the real run typing "Ra" updated search().

      
Added
Property vs attribute. After typing "Ra", the input's value property was "Ra" while getAttribute('value') returned null. [value] and ngModel set properties; the HTML attribute only holds the initial value. Use [attr.x] only when there is no property (aria-*, colspan).

    

  


  

    
Check yourself

    
Answer out loud before you open each card.

    

      
Name the four kinds of binding and their direction.Show answer
        
Interpolation {{ }} and property binding [ ]: class → DOM. Event binding ( ): DOM → class. Two-way [( )]: both.

      
What does [(ngModel)]="search" expand to?Show answer
        
[ngModel]="search()" (ngModelChange)="search.set($event)" for a signal (or search = $event for a plain field). It needs FormsModule, otherwise NG8002.

      
disabled="false" on a button: enabled or disabled?Show answer
        
Disabled. A static attribute is a string, and any value of the disabled attribute disables. Use [disabled]="false".

      
When do you need [attr.x]?Show answer
        
When the HTML attribute has no matching DOM property: aria-*, colspan, data-*, SVG attributes. Binding null removes the attribute.

      
(click)="toggle" without parentheses: what happens?Show answer
        
Nothing on click: the expression just reads the function. The build warns NG8111: Function in event binding should be invoked: toggle().

      
Is title="{{ patient.name }}" different from [title]="patient.name"?Show answer
        
No, interpolation in an attribute is turned into the same property binding. Prefer [title] for non-string values.
