Conditionals & loops

  • if / elif / else checks conditions top to bottom and runs only the first branch that is true.
  • A for loop takes items one at a time from any sequence (list, string, range()); a while loop repeats as long as a condition stays true.
  • continue skips to the next item; break leaves the loop completely.
  • Indentation is the syntax: the indented lines under a colon are the block.

Reference: truthiness and match

    

      
Falsy values (everything else is truthy)
False · None · 0 · 0.0 · "" · [] · () · {} · set() · range(0)
So if items: means "if the list isn't empty".

      
match / case (Python 3.10+)
match status:    case "urgent": ...    case "ok" | "done": ...    case _: ...
Like a switch, but it can also match shapes (tuples, dicts, classes). No fall-through.
