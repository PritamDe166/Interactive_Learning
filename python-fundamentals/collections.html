Collections: list, tuple, set, dict

  • list [ ]: ordered, changeable, duplicates allowed. The everyday container.
  • tuple ( ): ordered but fixed. Good for records like (lat, lon) and for unpacking.
  • set { }: no order, no duplicates, very fast in checks, maths like union and intersection.
  • dict {key: value}: look things up by key. Keys are unique; insertion order is kept.
