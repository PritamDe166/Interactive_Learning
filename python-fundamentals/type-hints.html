Type hints

  • Type hints describe what a value should be: def with_tax(amount: float) -> float:.
  • Python does not check them at run time. They're read by your editor and by type checkers such as mypy or pyright before the code runs.
  • Modern syntax: list[int], dict[str, float], str | None (3.10+). No typing import needed for these.
  • Hints document intent, power autocomplete, and catch whole classes of bugs (None, wrong types, typos) early: the closest Python gets to C#'s compiler checks.
