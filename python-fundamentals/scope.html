Scope (LEGB)

  • To find a name, Python searches four places in order: Local → Enclosing function → Global (module) → Built-ins. First match wins.
  • Reading an outer name works automatically. Assigning to a name inside a function makes it local to that function.
  • To assign to a module-level name, declare global; for the enclosing function's name, declare nonlocal.
  • An inner function that keeps using an outer function's variable after it returns is a closure.

Cheat-sheet

  • Read an outer variable→Just use it (LEGB finds it)
  • Change a module variable inside a function→Prefer passing it in and returning; otherwise global x
  • Change an enclosing function's variable→nonlocal x
  • UnboundLocalError→You assign to that name somewhere in the function: it's local everywhere in it
  • A variable named list / str / id→Rename it; it hides the built-in
  • Keep state between calls without globals→A closure, or a class

Reference: what creates a scope

ConstructNew scope?Note
Module (the .py file)yes: globalone per file; import gives access to another module's globals
def / lambdayes: locala new frame on every call
Class bodyyes, but specialmethods don't see class-level names directly; use self.x or ClassName.x
Comprehensionyesits loop variable doesn't leak
if / for / while / with / trynonames created inside live in the surrounding function or module

Where a variable lives. A variable created in the outer function and only read by the inner one belongs to the enclosing scope, not the inner function.

A function that's never called never runs. Defining local_scope() does nothing until you call it. And PEP 8 uses snake_case for function names (fetch_global_var, not fetchGlobalVar).

UnboundLocalError (puzzle 2) is the error you hit when you forget global/nonlocal; the repo shows the fix but not the failure. Since 3.12 the message says "cannot access local variable … where it is not associated with a value".

Use global sparingly. Functions that take inputs and return outputs are easier to test. Closures (shown in the walkthrough) are the foundation for decorators.
