Scope (LEGB)

  • To find a name, Python searches four places in order: Local → Enclosing function → Global (module) → Built-ins. First match wins.
  • Reading an outer name works automatically. Assigning to a name inside a function makes it local to that function.
  • To assign to a module-level name, declare global; for the enclosing function's name, declare nonlocal.
  • An inner function that keeps using an outer function's variable after it returns is a closure.

Cheat-sheet

  • Read an outer variable→Just use it (LEGB finds it)
  • Change a module variable inside a function→Prefer passing it in and returning; otherwise global x
  • Change an enclosing function's variable→nonlocal x
  • UnboundLocalError→You assign to that name somewhere in the function: it's local everywhere in it
  • A variable named list / str / id→Rename it; it hides the built-in
  • Keep state between calls without globals→A closure, or a class
