Functional tools & itertools

  • Functions are objects: you can pass them to other functions. lambda writes a small one inline: lambda p: p[1].
  • sorted(items, key=f) sorts by f(item), not by the item itself. Same key= works for min, max and groupby.
  • map(f, xs) transforms, filter(f, xs) keeps items where f is true, reduce(f, xs, start) folds them into one value. A comprehension is often clearer for the first two.
  • itertools has lazy building blocks: chain, islice, groupby, count…

Cheat-sheet

  • Sort records by a field→sorted(rows, key=lambda r: r["fee"])
  • Descending / two levels→reverse=True / tuple key (-fee, name)
  • Same, faster and named→from operator import itemgetter, attrgetter
  • Transform or filter a list→A comprehension; map/filter when you already have a named function
  • Combine everything into one value→sum / max / any / all first; reduce for anything else
  • Group records→Sort by the key, then groupby; or build a dict of lists
  • Join several iterables→chain(a, b, c)
