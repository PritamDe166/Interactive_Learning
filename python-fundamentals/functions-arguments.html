Functions & arguments

  • def creates a function object and a name for it. Calling it creates a fresh frame holding the parameters and local variables.
  • Arguments bind to parameters by position, then by keyword; anything not given falls back to its default.
  • *args collects extra positional values into a tuple; **kwargs collects extra keywords into a dict.
  • return a, b returns one tuple. No return means the function returns None.
  • Defaults are created once, when def runs. A mutable default like [] is shared between calls.

Cheat-sheet

  • Optional parameter→Give it a default: def f(x, rate=0.18)
  • Default should be a list / dict→=None, then create it inside
  • Any number of values→*args (tuple)
  • Any extra named options→**kwargs (dict)
  • Force callers to name an argument→Put it after *: def f(a, *, urgent=False)
  • Return several things→return a, b and unpack x, y = f()
  • Pass a list / dict as separate arguments→f(*items) / f(**options)

Reference: parameter order

def f(pos_only, /, normal, default=1, *args, kw_only, kw_default=2, **kwargs):
  • before /positional only (3.8+); rarely needed in your own code
  • normal, default=1by position or keyword; defaults must come after non-defaults
  • *args or a bare *everything after it must be passed by keyword
  • **kwargsalways last
  • In callspositional arguments first, then keywords: f(1, b=2), never f(b=2, 1)
