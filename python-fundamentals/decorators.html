Decorators

  • A decorator is a function that takes a function and returns a replacement, usually a wrapper that adds behaviour before and after the original.
  • @log_calls above def f is shorthand for f = log_calls(f), run once, when the def runs.
  • The wrapper uses *args, **kwargs to accept any arguments and a closure to remember the original function.
  • Always add @functools.wraps(func) so the wrapper keeps the original's name and docstring. Used everywhere: logging, timing, caching, permissions, web routes.

Cheat-sheet

    
    
      
  • Add behaviour around many functions→Write a decorator once, put @it on each
    • 
      
  • Writing the wrapper→def wrapper(*args, **kwargs): … return func(*args, **kwargs)
    • 
      
  • Keep the name and docstring→@functools.wraps(func)
    • 
      
  • Decorator that takes settings→Three levels: def require_role(role): def decorator(func): def wrapper(...)
    • 
      
  • Cache pure function results→@functools.cache / @lru_cache(maxsize=…)
    • 
      
  • Several decorators→Bottom one wraps first; top one runs first
