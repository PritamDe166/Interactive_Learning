Iterators & generators

  • A for loop calls iter() on the object to get an iterator, then next() until it raises StopIteration.
  • A function containing yield is a generator function: calling it runs nothing yet and returns a generator object.
  • Each next() runs the body up to the next yield, hands out that value and pauses, keeping its local variables.
  • Generators are lazy: values are made one at a time, so a stream of a million rows needs memory for one. They can be used once.

  • Produce a sequence step by step→A generator function with yield

    • 
      
  • Huge file or API pages→Yield one record at a time instead of building a list
