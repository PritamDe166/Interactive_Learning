print, input & f-strings

  • print() turns each argument into text, joins them with sep (a space) and finishes with end (a newline).
  • input() shows a prompt and always returns a str, even when the user types a number.
  • f-strings (f"Hi {name}") evaluate the code inside {} and drop the result into the text.
  • After a colon, a format spec controls the look: {fee:,.2f} → 1,234.50.

Corrected
The comma adds its own space. In Print_statements.py, print("Colors are "+": "+"Oranges"," Apples") prints Colors are : Oranges··Apples with two spaces: one from sep, one inside " Apples".

      
Added
Prefer f-strings. "{} {}".format(a, b) (your InputOutput examples) and "%s" % a still work and appear in older code, but f-strings are shorter, faster and read left to right.

      
Added
input() + int() can fail. If the user types abc, int() raises ValueError. Wrapping it in try/except is covered in Errors & exceptions.

      
Updated
Newer f-string features: since Python 3.12 you can reuse the same quote type inside the braces (f"{d["key"]}") and split long expressions across lines. Python 3.14 adds t-strings (t"..."), template strings that keep the parts separate for safe HTML or SQL building.
