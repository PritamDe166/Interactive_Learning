Classes & objects

  • A class is a blueprint; calling it (Patient("Asha", 35)) creates an instance, a new object with its own attributes.
  • __init__ runs right after the object is created to fill in its attributes. self is that new object.
  • Methods are functions defined in the class. asha.book("9:00") is really Patient.book(asha, "9:00").
  • A subclass inherits everything from its parent, can override methods, and calls the parent's version with super().
  • Looking up obj.x checks the instance, then its class, then the parent classes.

Cheat-sheet

  • Data + behaviour that belong together→A class (or @dataclass for mostly-data)
  • Per-object values→Set on self in __init__
  • Value shared by all instances→Class attribute, but never a mutable one like []
  • Reuse and extend a class→class Child(Parent): + super().__init__(...)
  • Change one method in a subclass→Override it; call super().method() to keep the parent's part
  • Is it this kind of thing?→isinstance(obj, Cls) (works with subclasses)
  • Something went wrong in a method→raise, don't just print
