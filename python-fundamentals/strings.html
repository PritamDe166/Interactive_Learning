Strings in depth

  • A str is an ordered sequence of characters. Each one has a position: 0 from the left, -1 from the right.
  • Slicing s[start:stop:step] copies a part; stop is excluded and missing values mean "from the start" / "to the end".
  • Strings are immutable: methods like upper(), strip() and replace() return a new string and leave the original alone.
  • split() turns text into a list; "sep".join(list) turns a list back into text.

Added
Why this page exists: the repo uses strings everywhere but has no file on slicing or methods. These are among the most-used Python skills, so this is a gap topic.

      
Added
strip() removes characters, not a word. "report.csv".strip(".csv") gives 'report' by luck but "vacs.csv".strip(".csv") gives ''. Use removesuffix(".csv").

      
Added
Comparing text from users: normalise first with s.strip().lower() (or casefold() for non-English text) before using ==.

      
Added
Multi-line strings use triple quotes """..."""; the newlines are part of the value. Adjacent literals join automatically: "ab" "cd" is 'abcd'.
